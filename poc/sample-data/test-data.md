# テスト用ダミーデータ一式（訪問準備エージェント PoC）

> **【重要】本ファイルはすべてPoCテスト用のダミーデータです。**
> 登場する企業名・人物名・数値・ニュース・提携情報はすべて架空であり、実在の企業・団体・人物とは一切関係ありません。「SPEEDA検索結果の貼り付け例」も、スピーダ（旧SPEEDA）の実際のコンテンツではなく、画面からのコピー＆ペーストを模して作成した架空テキストです。

## 0. このファイルの使い方

Copilot Studio エージェントの動作確認に使うテストデータ一式です。以下の順で使います。

1. **セクション1.1のCSV** をエージェントに貼り付け → ステップ①（予定解析・名寄せ）の出力を確認
2. 名寄せ確定後、ステップ②（SPEEDA検索キット生成）の出力を確認
3. **セクション2.1の貼り付け例（一括）** をエージェントに貼り戻し → ステップ③（ブリーフ生成）の出力を **セクション3の期待出力例** と見比べる。分割貼り付けのテスト（チェックリストD-1）には **セクション2.2（2分割・合図付き）** を使う
4. **セクション4のチェックリスト** で合否を記録する
