# 路線便タリフ計算 PoC

`docs/rosenbin-tariff-tools-survey.md`（市販調査）の結論「計算は表引きの算数、難所はタリフのデータ化」を実証する最小PoC。

**運賃額はすべて架空**（`make_dummy_tariff.py` が生成するダミー3社分）。実在の運送会社・タリフとは無関係。

## 使い方

```bash
cd poc
python3 make_dummy_tariff.py                 # ダミーマスタ生成（初回のみ）
python3 tariff_calc.py --from 東京 --to 大阪 --weight 80 --volume 0.4
python3 tariff_calc.py --from 埼玉 --to 福岡 --weight 450 --timed
```

出力例:

## データスキーマ（実タリフへの差し替え口）

| ファイル | 列 | 意味 |
|---|---|---|
| `data/zones.csv` | carrier, prefecture, zone | 会社別の地帯区分（都道府県→地帯）。会社ごとに切り方が違ってよい |
| `data/tariff.csv` | carrier, from_zone, to_zone, max_kg, fare | 発地帯×着地帯×重量帯上限→基準運賃（ロングフォーマット） |
| `data/contracts.csv` | carrier, discount_rate, volume_kg_per_m3, fuel_surcharge_rate, min_fare, timed_delivery_fee | 契約条件（割引率・容積換算係数・燃料サーチャージ率・最低運賃・時間指定割増） |

実運用では `make_dummy_tariff.py` を捨て、契約タリフをこのスキーマのCSVに起こして差し替える。

## 計算ロジック

```
課金重量 = max(実重量, ceil(容積 × 換算係数))
基準運賃 = tariff[地帯(発), 地帯(着), 課金重量が収まる最小の重量帯]
合計    = ceil10( 基準運賃 × (1−割引率) + 時間指定割増 ) にサーチャージを加算し、最低運賃でフロア
```

## 既知の簡略化（実タリフ化するときの合わせ込みポイント）

- 計算順序・端数処理は仮置き（割引→割増→サーチャージ→10円単位切り上げ→最低運賃）。**会社ごとに流儀が違うので、過去の請求書と突合して合わせ込むのが本番の山場**
- 割増は時間指定のみ。実際は特大品・離島/遠隔地・現地搬入・着店止め等がある
- 地帯は都道府県単位。実際は市区町村例外（遠隔地割増など）がある
- 入力は都道府県名（「札幌」ではなく「北海道」）。沖縄はダミー3社とも対象外設定
- 重量帯上限（2,000kg）超過は貸切見積り扱いで対象外表示
- サーチャージ率・タリフ改定の履歴管理（適用日つきマスタ）は未実装
