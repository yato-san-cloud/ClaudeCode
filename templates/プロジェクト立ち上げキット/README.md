# プロジェクト立ち上げキット

新しい物流プロジェクトの初日に、骨格(フォルダ構成・MOC・案件用CLAUDE.md・申し送り規約)を **10分** で用意するためのキット。
PG1(先行案件)で確立したやり方を汎用化したもの。案件固有の中身はここには置かない。

## 中身

| ファイル | 役割 |
|---|---|
| `フォルダ構成雛形.md` | Drive上に作る番号フォルダ(00_〜99_)の標準と、各フォルダの用途・置くもの/置かないもの |
| `MOC雛形.md` | 目次ノート(MOC.md)の初期構造。ステータス欄・★運用・（参考、最新はvX）注記の書き方 |
| `CLAUDE.md雛形.md` | 案件フォルダ直下に置くAI作業指示。読み取り専用原則・命名規則参照・機密区分・用語集欄 |
| `申し送りプロトコル.md` | 依頼_/回答_/通知_ 形式によるセッション間・担当者間の通信規約 |
| (Skill本体) | `.claude/skills/project-init/SKILL.md` — このキットを対話式に展開するSkill |

## 展開手順(新案件初日)

1. **対話**: Claude Codeで `新案件` `立ち上げ` `プロジェクト初期化` のいずれかを含む依頼をすると `project-init` Skillが起動し、案件名・顧客名・関係者・フェーズゲート名・開始日などを聞く
2. **雛形置換**: Skillが本キットの4ファイル(フォルダ構成雛形/MOC雛形/CLAUDE.md雛形/申し送りプロトコル)のプレースホルダ(`{{案件名}}` 等)を回答内容で置換し、チャット上に生成物一式を提示する
3. **確認**: 内容(特にフォルダ構成の要否・機密区分の初期値)を人間が確認・修正する
4. **Driveへの配置は人間が実施**: 生成されたMarkdownをコピーし、Google Drive上の案件フォルダに実ファイルとして作成する。番号フォルダの作成も人間が行う。**AIはDriveへの書き込みを一切行わない**

## 前提・安全原則

- 本Skill・キットはドラフト生成のみ。Google Driveへの接続・フォルダ作成・ファイル書き込みは行わない(本リポジトリ共通ルール、`README.md` 参照)
- 命名・版管理・正本の扱いは `docs/02_運用ルール_命名・版管理・正本.md` に従う。キット内の雛形もこのルールに準拠済み
- 生成した案件用CLAUDE.mdは、案件フォルダの性質に応じて人間が加筆してよい(本キットは最小骨格)
- 🔒私的メモ(人物評・交渉戦術)欄は雛形に含めない。必要になった場合も配布物・引継ぎ書とは別ファイルで管理する運用を、案件用CLAUDE.mdの機密区分欄で明記する

## 使うタイミング

- 新規案件の受注・アサイン初日
- 既存案件のフォルダ構成が崩れて仕切り直したいとき(既存ファイルの遡及リネームはしない。新規追加分のみ整理)
