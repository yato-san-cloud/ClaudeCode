# PLAUD議事録 自動整理システム

PLAUD(AIボイスレコーダー)の録音を毎日自動で構造化された議事録に整理し、Boxに顧客別で保存するパイプライン。Claude Code(claude.ai/code)のセッションが実行主体。

## 全体像

```
PLAUD録音 → PLAUD MCP(要約取得) → Claude(議事録整理・顧客判定) → Box(顧客別フォルダに保存)
                                                                  ├ index.html / index.md(全件インデックス)
                                                                  ├ _processed.json(処理済み管理・正データ)
                                                                  └ 会社Copilot(Boxコネクタ経由で検索・回答)
```

## 構成要素

| 要素 | 場所 | 役割 |
|---|---|---|
| PLAUD MCP | claude.aiカスタムコネクタ `https://mcp.plaud.ai/mcp` | 録音一覧・AI要約・文字起こしの取得 |
| Box「議事録」フォルダ | folder_id: `400559758901` | 保存先ルート。顧客別サブフォルダ+インデックス |
| `_運用ルール.md` | Box議事録フォルダ直下 | 処理手順の正本(このリポジトリの `runbook.md` と同内容) |
| `_processed.json` | file_id: `2350978796466` | 処理済み録音ID+title/summary(インデックス再生成の正データ) |
| `index.html` | file_id: `2350976207572` | 顧客別×日付降順の全件インデックス |
| 毎日の定期実行 | Claude Codeセッションのcron(毎朝6:53 JST) | 新規録音の自動処理 |
| Copilotエージェント | Box `_Copilotエージェント設定手順.md` (file_id: `2352740284529`) | 議事録Q&A用エージェントの設定手順と指示文 |

## セッションが切れたときの復旧手順

1. 新しいClaude Codeセッションでこのリポジトリを開く(このREADMEが読まれる)
2. PLAUDとBoxのコネクタがチャットで有効か確認(`ListConnectors`で `enabledInChat: true`)
3. `runbook.md`(= Boxの `_運用ルール.md`)の手順どおり、`daily-task-prompt.md` の内容で毎日のcronを再作成する(cronはセッション限定・最長7日で消えるため)
4. 消えていた期間の録音は `_processed.json` との差分として次回実行時に自動で拾われる(取りこぼしなし)

## 既知の制約

- BoxのMCP連携はテキストのみ受け付けるため、docx等のバイナリはBoxへ自動保存できない。Word版が必要なときはチャットでdocxを生成して渡す
- Google Driveは会社非公式のため使用しない(2026-07-17 ユーザー決定)
- 恒久的なRoutine(サーバー側スケジュール)は本環境ではツール承認の問題で作成できておらず、セッション内cronで代替中
