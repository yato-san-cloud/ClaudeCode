# PLAUD議事録 自動整理の運用ルール(正本はBoxの `_運用ルール.md`)

毎日の定期タスクがBoxの「議事録」フォルダを管理する。人間が読むためのルール兼、将来のセッションへの引き継ぎメモ。Box側と本ファイルは同内容を保つこと。

## 大方針

- **保存先はBoxのみ**。Google Driveは会社オフィシャルではないため使用しない(2026-07-17 ユーザー決定)
- Boxに入れるのは、会社CopilotのBoxコネクタから議事録を検索・要約させる用途のため。テキスト(md/html)中心が望ましい

## フォルダ構成

- `議事録/` (folder_id: 400559758901)
  - `index.html` (file_id: 2350976207572) — 全議事録のインデックス(ブラウザ用)。毎回再生成
  - `index.md` (file_id: 2407409730832) — 同内容のMarkdown版(Boxプレビュー用)。毎回再生成
  - `_processed.json` (file_id: 2350978796466) — 処理済みPLAUD録音のリスト。title/summaryを含み、インデックス再生成の正データ
  - `_運用ルール.md` (file_id: 2350987943846) — 本ルールの正本
  - `_Copilotエージェント設定手順.md` (file_id: 2352740284529) — 議事録Q&A用Copilotエージェントの設定手順
  - 顧客別サブフォルダ: ローソン(400557589411) / NW(400687725127) / 三星商事(400710014177) / ユニ和(400710625753) / カトープレジャー(409016728554) / ウェルシア(409020215156) / 社内・その他(400559978041)
  - 新しい顧客が出てきたら顧客名でサブフォルダを新規作成し、インデックスにセクションを追加する

## 毎日の処理フロー

1. PLAUD MCP(list_files)で録音一覧を取得する
2. `_processed.json` にあるIDはスキップ
3. 各録音の要約(get_note)・必要なら文字起こし(get_transcript)を取得し、以下の構成のMarkdownに整理する:
   - 会議概要(日時・参加者・目的・出典PLAUD録音ID)
   - 要点サマリ(3〜5行)
   - 決定事項(番号付き)
   - アクションアイテム(担当つき、カテゴリ別)
   - 議論の詳細(トピック別)
   - 未解決事項(要フォロー)
   - ※会議でない個人メモ・思考ノートは「概要/要点/内容整理/今後のポイント」の簡易構成でよい
4. 内容から顧客を推定して該当サブフォルダに保存。判断できなければ「社内・その他」
5. ファイル名: `YYYYMMDD_会議名.md`(40文字目安)。同内容のスタイル付きHTML版(`同名.html`)も保存する
6. `index.html` と `index.md` を `_processed.json` のtitle/summaryから再生成して `upload_file_version` で更新(顧客別セクション×日付降順、列: 日付/会議名/要点/Markdown/HTML)
7. `_processed.json` に処理済みエントリを追記: `{plaud_id, meeting_date, customer, title, summary, md_file_id, html_file_id, processed_at, skipped:false}`
8. 内容が実質ない録音(数秒・無音・雑談のみ)は保存せず `{plaud_id, meeting_date, skipped:true, reason}` で記録のみ(再処理防止)
9. **文字起こし・AI要約が未生成の録音**(録音は長いがget_note/get_transcriptが空)は `_processed.json` に**記録しない**。PLAUD側で文字起こしが生成され次第、翌日以降の定期実行が自動で拾う

## 顧客判定の目安

- ローソン: ローソン向け提案・D+2/D2切替・浜松店舗移管・袋井サテライト・静岡DDC・オムニソーター・配送コース/ダイヤ・二拠点化
- NW: NW社(片桐社長・黛取締役・ネオ/ネオロジ)、新富士・DPL倉庫のEC物販・CD/DVD出荷・検品梱包・推奨箱・Tソート/T-SOT・料金改定交渉
- カトープレジャー: 海洋深層水・飲料水事業
- ウェルシア: ドラッグストア物流(名古屋新センター等)
- 協力会社訪問・社内定例・個人メモ・複数顧客混在・判定不能 → 社内・その他

## Word(docx)版について

- BoxのMCPツールはテキストのみ受け付け、バイナリ(docx)を直接アップロードできない
- docx版が必要なときだけpython-docxでローカル生成し、チャットでユーザーに直接送付する。Boxへは置かない(置けない)
- Google Driveへの保存は行わない

## 注意

- 元のPLAUD録音・文字起こしは削除しない(整理版の保存のみ)
- 同名ファイルがある場合は `upload_file_version` で版を上げる
- PLAUD MCPが未接続・認証切れの場合は処理をスキップしてユーザーに知らせる
- MCPサーバー名は再接続でUUID接頭辞に変わることがある。ツールが見つからないときはToolSearchのキーワード検索で探す
