# タリフ番長

路線便（特別積合せ）運賃の**計算・複数社比較・一括見積り・請求照合・タリフマスタ管理**を、単一HTMLファイルだけで行うローカル完結ツール。`app/tariff-bancho.html` をブラウザで開くだけで動く。サーバー・インストール・外部送信なし。

市販調査（`docs/rosenbin-tariff-tools-survey.md`）の結論——「計算は算数、難所は各社バラバラなタリフのデータ化。市販は導入型で重く、タリフ登録はどのみち自前」——への回答として、**タリフ登録の楽さに全振り**した設計。

## 機能

| タブ | できること |
|---|---|
| 単発計算 | 発着・重量・容積（寸法からの換算ヘルパー付き）・時間指定・出荷日 → 全社の運賃を安い順に内訳付きで表示。**入力すると即再計算（ライブ）**、発着スワップ、最安カードに定価比の割引率表示 |
| 一括見積り | 出荷リストをExcelコピペ or **CSV/TSVファイル読込（UTF-8/Shift_JIS自動判定）** → 全行×全社を一括計算。「全件を1社」対「行ごと最安社」の削減額を**全社対応可能な行ベースで公平比較**（タイル＋チャート） |
| 請求照合 | 請求明細をコピペ/ファイル読込 → 理論値と突合、差異行をハイライト。許容差設定・差異合計（払い過ぎ疑い額）・**判定不能の理由を可視列で表示** |
| タリフマスタ | 会社ごとの割引率・容積換算・最低運賃・時間指定割増・燃料サーチャージ履歴（適用日付き）・地帯区分・運賃表を管理。**紙面イメージのマトリクス表をそのまま貼って取込可**。未保存変更のインジケータと破棄ガード付き |
| データ管理 | JSONエクスポート/インポート（コピペ方式）、デモデータ再読込、全削除（誤爆防止の2段階クリック） |

### 入力まわりの気配り

- 見出し行は**列順自由**。「重量(kg)」「請求金額」「重量ｋｇ」のような表記ゆれも吸収し、**どの列を何と解釈したかを結果に明示**（重要列が見つからなければ警告）
- 引用符付きCSV（`"15,120"`）、全角数字、`2026/8/14`形式の日付、¥記号に対応
- タブ状態はURLハッシュに保存（リロード・共有で復元）。タブは矢印キーでも移動可能
- 初回はオンボーディングから1クリックでデモの一括見積りを体験可能
- 見積り結果はそのまま印刷可能（入力フォームは印刷時に自動非表示）

## データの置き場所と秘匿性

- すべて**ブラウザのlocalStorageのみ**。外部への送信は一切ない（荷主別の契約タリフは営業秘密——SaaSに上げたくない情報を端末から出さない）
- バックアップ・共有はデータ管理タブのJSONコピペで

## デモデータ

初期状態は架空の3社（A運輸・B急便・C物流）のダミータリフ入り。**実在の運送会社・運賃とは無関係**。会社ごとに地帯の切り方が違う（B急便は関東を南北分割、C物流は東西統合）路線便の実態を模している。

## 計算ロジック

Python版PoC（`poc/tariff_calc.py`）と同一：

```
課金重量 = max(実重量, ceil(容積 × 換算係数))
基準運賃 = タリフ表[発地帯, 着地帯, 課金重量が収まる最小の重量帯]
合計 = max( ceil10(基準運賃 × (1−割引率) + 時間指定割増 + 燃料サーチャージ), 最低運賃 )
燃料サーチャージ = (割引後 + 時間指定割増) × 出荷日時点の適用率
```

計算順序・端数処理（10円単位切り上げ）は仮置き。実契約では会社ごとに流儀が違うため、**過去の請求書と照合タブで突合して合わせ込む**こと。

## テスト

```bash
node app/tests/parity.mjs   # JSエンジンとPython版の計算一致（1,000ケース×3社）
```

ブラウザ実機のスモークテスト（Playwright・16項目）はセッション内で実行済み：オンボーディング・ライブ再計算・京都正規化回帰・括弧付き見出し/引用符CSV/全角入力・未保存ガード・ハッシュ復元・2段階確認・コンソールエラーなしを確認。さらに5次元（計算・JS/DOM・CSS/テーマ・パース・UX）×敵対的検証の15エージェントレビューを実施し、確定指摘をすべて修正済み。

## 実タリフへの差し替え手順

1. タリフマスタ → 会社を追加
2. 契約条件（割引率・容積換算kg/m³・最低運賃・時間指定割増・サーチャージ率と適用日）を入力
3. 地帯区分：地方ごと一括追記＋例外の県だけ手直し
4. 運賃表：紙面のマトリクス（1行目=重量帯上限、以降=着地帯×運賃）を発地帯ごとに貼って「変換して追記」
5. 保存 → 請求書1〜2ヶ月分を照合タブに貼り、差異ゼロになるまで条件を調整
