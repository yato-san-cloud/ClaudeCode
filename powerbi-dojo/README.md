物流実務に特化して Power BI の M言語(Power Query)と DAX を本気で学ぶアプリです。
**`index.html` をブラウザで開くだけ**で動きます(インストール・ネット接続不要)。

## 演習は3タイプ

- **4択クイズ** — ありがちな勘違いを突く選択肢と、全問に「なぜ+実務でどう効くか」の解説
- **穴埋め(Duolingo式トークンバンク)** — コードの空欄にチップをはめて完成させる
- **記述(コードエディター)** — M/DAXシンタックスハイライト付きエディターに実際にタイプ。全角括弧・全角スペースは自動補正、惜しい答えには「おしい!」再挑戦、ヒント・白旗つき

## 毎日続く仕組み

- ⚔️ **今日の配送便** — 1日1回・5問・XP2倍(弱点問題を優先ミックス)
- 🎯 **デイリークエスト3件** — 達成でXP・ストリークフリーズを獲得
- 🔥 **ストリーク+フリーズ** — 1日休んでもフリーズが連続記録を守る
- 🥋 **帯システム** — 白帯→…→黒帯→師範(XPで昇段、昇段演出つき)
- ⭐ **スキルパス** — レッスンノードを★1〜3で解放していくDuolingo風マップ
- 🏅 **実績バッジ** / 🐕‍🦺 **マスコット「ロジ柴」** / 🎉 効果音・紙吹雪(設定でミュート可)
- 進捗はブラウザのlocalStorageに自動保存。v1で貯めたXP・連続記録は初回起動時に自動引き継ぎ

## 開発

```
node build.js                          # src/ から index.html を生成
node spec/validate.js src/units/*.js   # 教材データのスキーマ検証
```

- `src/app.js` アプリシェル(状態・画面・ゲーミフィケーション) / `src/editor.js` エディター&判定 / `src/units/unitNN.js` 教材データ
- 仕様書は `spec/`(カリキュラム・スキーマ・UI契約)。教材を追加するときは SCHEMA.md に従い validate を通すこと
- 依存ライブラリなし・単一HTML出力・ライト/ダーク自動対応・モバイル対応
