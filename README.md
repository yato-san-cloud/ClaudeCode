# 教習所トレーナー（方向転換・縦列）

卒検で崩れやすい **方向転換（右バック／左バック）** と **縦列駐車** の
「切り始めの基準点」「進入の軌跡」「切り返しの合図」を、
スマホ／PCのブラウザで反復練習するための1ファイル・モックアップ。

> ねらいは「早切りの矯正」と「切り返しの判断」を安全に何度も試すこと。
> ハンドルを回す腕の速さやクラッチ感といった“操作の体の動き”は実車練習で補う前提。

## 使い方（横向き・運転席モード）

`index.html` を**横向き（ランドスケープ）**で開く。両手で持って**両親指で操作**するゲームHUD配置：

- **上＝フロントガラス視界**：前方の目標（柵・枠・目安ライン）が運転席からどう見えるかを3D描画。ボンネット・Aピラー・奥行きグリッドつき。ミラー3枚は実車と同じくこの中に配置（左右下隅＝ドアミラー、上中央＝ルームミラー、ボンネット上＝速度計）
- **👀後方目視で振り返り視界に切替**：後方目視ボタンで、フロント視界が**後ろを振り向いた実像**（リヤウインド＋Cピラー＋ヘッドレスト越し）に切り替わる。ボタン押すだけの安全確認ではなく、**リヤウインド越しに柵の角がどう見えるかで停止位置を体感**できる。柵の角が**Cピラーの際に来た瞬間＝切り始めの位置**（🎯で強調・幾何校正済み。手前すぎ／行き過ぎでは光らない）
- **中央＝俯瞰図**（フロント視界・ミラーと重ならない専用帯）：コース・お手本の軌跡・切り始めの目安ライン・**4輪の動的タイヤ予測線**（ハンドルに追従）・縁石＋柵・コース上の「今！」合図
- **右下＝シフト(P/R/N/D)＋ハンドル（右親指）**：ハンドルは指でドラッグして回す（微調整可・**ロック2.75回転＝実車相当**）。手のアイコンが追従し、大きく切ると持ち替え。`まっすぐ`で中央へ。シフトはハンドルのすぐ隣
- **左下＝ブレーキ／アクセル（左親指）**
- **上＝3枚ミラー（左ドア／ルームミラー／右ドア）＋速度(km/h)・ギア**。ミラーは簡易3Dで、**自車のリヤフェンダーと後輪、縁石／柵、駐車車両**が映る。後輪は**3D円柱として投影**しているので、実際のドアミラーの角度どおり——側面のリム面は見えず、前〜上へ回り込む**トレッド面と接地位置**が映る（＝後輪と縁石の間隔を読む練習ができる）。ミラーを下向きに調整すると後輪の接地位置が見やすい。**各ミラーをドラッグで角度調整**（振り返り視界の間はミラーは隠れる）
- **景色は昼間**（青空・遠景の樹林・明るいアスファルト）。フロント・ミラー・ルームミラー・振り返り視界すべて共通
- **クリープ**：ONならブレーキを離すと微速で進む。**左親指でブレーキを踏んだまま右親指でシフト→ハンドル**の分担運転が可能。止めて休みたい時は**Pに入れればブレーキを離しても停止**したまま

流れ（卒検と同じ手順で採点されます）：
1. **サイドブレーキ解除**（左下）→ シフト**D** → 目安ラインまで前進
2. 停止 → **安全確認**（ルームミラー・左右ミラーをタップ＋👀後方目視）→ シフト**R**
3. ハンドルを切りながら後退 → 枠内に正着
4. 停止 → シフト**P** → **サイドを掛けて完了** → 結果パネル（合否・減点内訳・手順チェック）

### 採点（模擬・100点満点／70点以上で合格）
- 脱輪・接触＝検定中止／切り返し2・3回目＝各−5点、4回目＝中止
- 後退時の安全不確認＝−10点／サイド戻し忘れ＝−10点／速度の出しすぎ＝−5点
- 当たり判定は検定基準：**タイヤが縁石を越える＝脱輪／車体が柵・駐車車両に触れる＝接触**。車体（鼻先・オーバーハング）が縁石の上空にはみ出すだけなら減点なし（初回に画面で通知）

### 学習支援
- **▶実演（お手本操作モード）**：教習所の標準技法「①ラインまで前進→②停止・安全確認→③止まったまま回し切る（約1.4回転）→④弧の間はハンドル保持→⑤止まって戻し切る→⑥まっすぐ奥へ→⑦P・サイドで完了」を自動運転で実演。ハンドルの回し始め・戻し始めの正しいタイミングと総回転量が目で見て分かる（切り遅れ→切り量過多の癖の矯正）
- **🎓解説付き実演（チュートリアルモード）**：実演の要所（進入の寄せ幅→柵の角が見えてもまだ下がらない→停止位置＝後輪を青ラインへ→**後方目視に切替＝柵の角がCピラー際に来ているか確認**→ミラーを下げて後輪を映す→回し切り→後輪と縁石の間隔の見方→鼻先はみ出しはOK→戻し切り）で自動停止し、解説カードがポップアップ。「つづける▶」タップで再開
- **「柵の角が見えてから下がる」癖づけ**：方向転換では、入れるポケットの角（縁石を囲う柵の角）がロック側ミラーに映った瞬間に緑リングで強調＋「見えた！」の合図。見える前に後退を始めると「まだ早い（手前すぎ）」と即指摘（検定NGの典型原因対策）
- **旋回中心(ICR)・回転半径・外輪スイング弧**をハンドル操作にリアルタイム連動表示（タイヤ線ON時）
- ハンドル下に**回転数｜舵角｜回転半径**を常時表示。**遊び（±8°）**も再現
- **自分の軌跡トレイル**が残り、お手本とのズレ＝癖が見える
- **検定モード**（上部「検定」）：お手本・タイヤ線・ヒントを消して本番同様に採点

## 本人仕様への差し替え

冒頭の `CONFIG` だけ変更すれば、教習車・コースに合わせられます。

```js
const CONFIG = {
  car:      { length, width, wheelbase, frontOverhang, maxSteerDeg, ... },
  perp:     { bayWidth /*間口*/, bayDepth /*奥行き*/, turninX, roadWidth /*道路幅3.5m*/, approachGap /*寄せ*/ },
  parallel: { approachY, turninX, theta1Deg, slotDepth, parkedLen, parkedW, ... },
};
```

- 車：マツダ アクセラ セダン（BM/BY型）のカタログ値を初期値に設定
- コース：方向転換の**道路幅は現地観測より3.5m**（教習所路の一般的な車線幅。※「バック路は法律で3.5m」と明記した条文は確認できず、幅員は各校の設計による。国家公安委員会基準で規定されるのは主にコース出入口の角の半径＝普通車2m以上）。進入の寄せは縁石から40cm。**3.5m道路では鼻先の振り出しに余裕ができ、寄せは20cm〜1.0mまで一発で入る**（寄せるほど後輪と柵の余裕は増える／3.5mでは鼻先が反対縁石を越えにくい）。その他は仮の標準値で、三島中央自動車学校（MCDS）の実寸が分かり次第差し替え
- 角の目印：**縁石を囲う柵（支柱＋横パイプ）**として描画（旧・縞ポールから変更）

## 設計メモ

- 物理：自転車モデル（アッカーマン近似）。低速の幾何・軌跡には十分
- 幾何：**お手本の軌跡を先に物理計算し、その着地点に枠を配置**して「解ける幾何」を保証
  - 方向転換：フルロック後退の1円弧／縦列：右→左のS字（2円弧）
  - 縦列の前後の車は「スイング包絡線＋余裕」に配置し、成功枠は車体ぴったりに分離
- 左バックは右バックの左右反転（幾何とお手本を y 反転して生成）
- 検証：ヘッドレスChromiumで、各課題「お手本経路が走行可能領域を出ない」「終端で枠に正着」を自動チェック
