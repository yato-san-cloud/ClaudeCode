# 教習所シミュレータ（場内課題・修了検定・路上教習）

卒検・修了検定にそのまま効く**運転シミュレータ**。単一の `index.html` だけで動き、
外部ファイル・通信・インストールは一切不要（オフライン／スマホのブラウザで動作）。

> もともとは「方向転換で曲がりきれない」を直すための教材。
> 現在は**場内8課題＋修了検定＋路上教習＋高速教習**と、**手続き生成のサウンド**まで入っています。

## 収録モード

### 駐車（卒検で崩れやすい）
| 課題 | 内容 |
|---|---|
| 方向転換（右バック／左バック） | 柵の角が見えてから下がる癖づけ。切り始め位置の矯正 |
| 縦列駐車 | 右→左のS字（2円弧）で枠へ |

### 場内コース
| 課題 | 内容 |
|---|---|
| 坂道発進 | 10%勾配。逆行30cm超で減点、50cm超で中止 |
| S字カーブ | 半径8mの曲線路（幅3.5m） |
| クランク（狭路） | 直角に折れる狭路。内輪差の練習 |
| 踏切 | 一時停止＋左右確認。**不停止は即中止** |
| 信号交差点 | 青9秒→黄3秒→赤9秒。**赤進入は即中止**、黄は「止まれたのに進入」のみ減点 |

### 🎓修了検定
S字→クランク→坂道→踏切→信号→方向転換を**連続で実施**し、持ち点100からの減点を通算。
中止事由が出たらその場で終了し、課題ごとの内訳を表示。

### 路上教習（一般道）
- **車線／経路グラフ**で生成した公道。交差点内の経路は曲率半径4.8mで、車の最小回転半径3.7mでも曲がれる
- **交通AI**：IDM追従、信号順守、優先／一時停止の譲り合い、交差点の競合予約（AI車10台＋歩行者9名）
- **歩行者**が横断歩道を渡る。信号・車の切れ目を見て判断
- 検定ルートを音声指示で誘導（直進→左折→左折→信号左折→一時停止して右折→路端停車）
- 路上の減点：速度超過（区間ごと・**+20km/h超で中止**）／合図／一時不停止／信号無視／
  巻き込み確認／車間距離／キープレフト／歩行者妨害／接触
- **飛び出し（危険予測）**：駐車車両の陰から歩行者が車道へ出る。速度を落として通過していれば
  間に合い、漫然と流していると間に合わない距離・タイミングで発生する

### 高速教習（入口ランプ → 料金所 → 合流 → 車線変更 → 出口）
停止状態から合流するような非現実的な始まり方はしない。**一般道から入口ランプを走っている状態**で始まる。

| 区間 | 見られること |
|---|---|
| 入口ランプ（230m・制限50km/h） | カーブで膨らまない速度。超過で減点 |
| **ETC料金所** | **20km/h以下**まで落とせばバーが開く。落とさなければ**バーに接触＝中止** |
| 加速車線（220m） | 本線の流れ（約100km/h）まで**加速して**入る。遅すぎる合流は減点 |
| 合流 | 合図（1秒以上）→ミラー→**目視**の手順。加速車線の終わりまでに入れなければ中止 |
| 本線・車線変更 | 3秒前の合図＋目視。速度超過（+20km/h超で中止）／最低速度／車間距離 |
| 出口 | 減速車線で十分に減速 → 停止 → P → サイド |

料金所はアイランド（縁石の島）・ETCアンテナのガントリー・機器ブース・赤白の発進制御棒まで立体で描画し、
**アイランドに乗り上げれば接触**として扱う。

### 事故の描写
衝突・人身事故は「やり直し」ではなく、**そこで何が起きたか**を出す。

- 衝突の瞬間：画面の揺れ、ガラスの破片、ボンネットの変形、対人ならボンネットへの乗り上げ
- その後：**衝突速度から推定した致死率**（30km/hを境に急上昇）、救護義務・過失運転致死傷罪・
  行政処分・賠償額、高速では**落下高さ換算のエネルギー**と**二次事故**、ガードレール外への避難

## 操作（横向き・運転席モード）

`index.html` を**横向き**で開く。両手の親指で操作するHUD配置：

- **上＝フロントガラス視界**：前方の3D描画。ボンネット・Aピラー・ミラー3枚を実車同様に配置
- **👀後方目視**：フロント視界が**振り返った実像**（リヤウインド＋Cピラー越し）に切替。
  柵の角がCピラー際に来た瞬間＝切り始めの位置（幾何校正済み）
- **中央＝俯瞰図**：コース・お手本の軌跡・4輪のタイヤ予測線。長いコースは**自車追従カメラ**
- **右下＝シフト(P/R/N/D)＋ハンドル**：ドラッグで回す（**ロック2.75回転＝実車相当**）
- **左下＝ブレーキ／アクセル／サイド／後方目視**、路上では**ウインカー**
- **ブレーキを踏みながらシフト・サイド操作**が可能（実車どおりの分担操作）
- **🔊音**トグル。進捗は自動保存され、メニューに `✓ 最高得点` が残る

## 実装のポイント

### 物理（駆動系）
エンジン（3800rpmピークの200Nm級トルク曲線）→**トルクコンバータ**→AT5速→終減速→タイヤ。
走行抵抗（転がり・空気・**勾配**・ブレーキ）と釣り合わせて加速度を積分する。

- トルコンは低速でスリップし、**エンジンブレーキが伝わらない**（実車がクリープで進めるのはこのため）
- クリープ推力は二分探索で較正し、平地クリープを正確に **0.55 m/s** に一致させてある
- **横グリップ限界**：必要な旋回加速度が μg を超えると実効切れ角を落とす＝アンダーステア。
  低速（駐車速度域）では発動せず、駐車の精度は不変
- **操舵レート制限**と**据え切りスクラブ**（音にも反映）

### サウンド（すべて手続き生成・音声ファイル不使用）
位相分散ウェーブテーブル＋非対称ソフトクリップで「録音した機械音」の質感。
点火パルスでAMした排気ノイズ、ギヤうなり、セル→初爆→ファーストアイドル、
タイヤのトレッドAM、スキール、風切り、環境音、15種の効果音。
状態遷移は**音声クロック**で駆動（背景タブでも破綻しない）。更新コストは 2.7µs/frame。

### 幾何の保証
**お手本の軌跡を先に物理計算し、その着地点に枠を配置**して「解ける幾何」を保証している。

- 曲線路は**コリドー（中心線＋半幅）**で表現。中心線をそのまま経路にすると内輪差ではみ出すため、
  **純追従（pure pursuit）で実際に走らせた軌跡**を理想経路とする
- 半幅は点ごとに変えられる。高速の入口は「ランプ8m→料金所10m→加速車線3.5m」と幅が変わるが、
  矩形を継ぎ足すと段差ができて縁を擦るため、**1本の幅の変わるコリドー**として滑らかに絞っている
- この車体（全長4.58m・軸距2.70m）がフルロック90°旋回に要する掃引幅は **3.05m**。
  ただし完全な直角コーナーはそれより厳しく、幅3.5mでは30万通り探索しても一発通過する線が
  存在しなかったため、クランクの角は半径5mで丸めて通過可能性を保証している
- 標高は1次元ランプのハイトフィールド。`mkProj` は元から `pz` を受け取るため投影は自然に立体になる

### 当たり判定（検定基準）
**タイヤが縁石を越える＝脱輪／車体が柵・車に触れる＝接触**。
車体が縁石の上空にはみ出すだけなら減点なし（3.5m道路の方向転換では鼻先のはみ出しは正常）。

## 本人仕様への差し替え

冒頭の `CONFIG` を変更すれば、教習車・コースに合わせられます。

```js
const CONFIG = {
  car:      { length, width, wheelbase, frontOverhang, maxSteerDeg, ... },
  perp:     { bayWidth, bayDepth, turninX, roadWidth /*3.5m*/, approachGap },
  parallel: { approachY, turninX, theta1Deg, slotDepth, parkedLen, parkedW, ... },
};
```

- 車：マツダ アクセラ セダン（BM/BY型）のカタログ値
- 道路幅 **3.5m**（三島中央自動車学校に確認した実寸）。3.5mなら寄せは20cm〜1.0mまで一発で入る

## 品質保証

`qa.mjs` がヘッドレスChromiumで自動検査：
起動・全10シナリオの理想経路の走行可能性・全ビューの描画・入力（ブレーキ保持中の分担操作、
全トグルの反転）・性能・音声。

性能は iPhone 横向き相当（844×390・DPR3）で計測し、60fps予算16.7msに対して
**最悪1.2ms/frame**（高速教習 0.9ms）。1km超の高速コースでは3D縁石をコース全長にわたり
0.5m刻みで射影していたため1フレーム数万回の計算になっていたので、
**自車の前後150mだけ・遠いほど粗く**刻むようにしてある。
