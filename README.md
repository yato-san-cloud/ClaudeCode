# 沼 — NUMA

漫画『賭博黙示録カイジ』に登場する伝説の一発台（羽根モノ）**「沼」** を、
ブラウザで遊べる物理シミュレーションとして再現したファンゲームです。

依存ライブラリ・外部アセットは一切なし。HTML5 Canvas と自前の 2D 物理エンジン、
WebAudio による合成サウンドだけで動く、完全な静的サイトです。

> ⚠️ ファンによる二次創作です。原作（福本伸行）および実在の遊技機・賭博とは一切関係ありません。

## 遊び方

1. `index.html` をブラウザで開く（または下記のローカルサーバーで配信）
2. **打ち始める** を押す
3. **発射**（または `Space` キー／画面タップ）で玉を打ち出す
4. **打ち出し強さ** スライダーで「ぶっこみ位置」を狙う
5. **自動**（`A` キー）でオート連射

### ルール

| 流れ | 内容 |
| --- | --- |
| ① 始動チャッカー | 玉が通過すると **羽根が開く**（中央=3回／左右=2回開放） |
| ② 羽根で捕獲 | 開いた羽根が、ヤクモノ天面の玉を **ステージ** へすくい込む |
| ③ Vゾーン | ステージの中央 **V** に沈めば **大当たり**。だが沼は **渋い**…… |
| ④ 大当たりラッシュ | 最大 **16ラウンド**、継続抽選つきの出玉ラッシュ |

**目標は収支 +¥10,000。** ステージ入賞の大半はハズレ。一握りの V を掴み取れ。

## ローカルで動かす

`file://` 直開きでも動きますが、サーバー経由を推奨します。

```sh
# どちらでも
python3 -m http.server 8080   # → http://localhost:8080
npm start
```

## テスト

ブラウザ無しでゲームロジック（物理・玉詰まり・大当たり整合）を検証します。

```sh
npm test        # node test/smoke.js
```

## 公開（GitHub Pages）

ビルド不要。リポジトリの **Settings → Pages** で対象ブランチの
ルート（`/`）を公開対象に指定するだけで、そのまま配信できます。

## 構成

```
index.html        画面・HUD・コントロール
css/style.css     カイジ風の配色とレイアウト（黒×緑×金×血の赤）
js/physics.js     2D物理エンジン（玉×釘の円衝突／玉×壁の線分衝突）
js/audio.js       WebAudio 合成サウンド（外部ファイル不要）
js/board.js       盤面レイアウト（釘・ヤクモノ・羽根・チャッカー・Vゾーン）と描画
js/game.js        ゲームロジック（状態機械・大当たり・収支）
js/main.js        起動・描画ループ・UIバインド
test/smoke.js     ヘッドレス検証
```

### 設計メモ

- **打ち出し** は実機同様、上部レールを滑って盤面へ入る `rail` ステートで表現。
  打ち出し強さが盤面への入射点（ぶっこみ位置）を決める。
- **羽根（屋根）** は線分ではなく **釘の列** で構成。釘は凸形状のため玉が尾根で
  詰まらず左右へ転がり落ちる。羽根が開くと中央（フタ）の釘だけが消えて捕獲口が開く。
- 衝突は **低速時に反発を 0** にして玉が斜面で跳ね続けないようにし、釘は常に反発させて
  頂点での静止を防ぐ。さらに保険として「玉詰まり解消」のインパルスを備える。
- **V抽選** は確率ベース。ステージ内では当落に応じて玉を V／ハズレへ自然に誘導する。
