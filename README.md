# ボキボキ・クリニック

**カイロプラクティック・アジャストメント シミュレーター**

「手術シミュレーター」的なノリで、カイロプラクターのアジャストメント（矯正）を
一連の流れとして体験できるブラウザゲームです。
依存ライブラリなし・外部アセットなしの単一 HTML ファイルで動きます。

```
open index.html      # ブラウザで開くだけ
```

ビルド・インストール・サーバ不要。描画はすべて Canvas、効果音はすべて WebAudio で合成しています
（「ポキッ」というキャビテーション音もノイズバースト＋バンドパスで生成）。

## 遊びかた

1日5人の患者を担当し、患者ごとに次の6フェーズを進めます。

| フェーズ | やること | 失敗すると |
|---|---|---|
| 1. 問診・スクリーニング | 病歴と所見からレッドフラッグを探し、施術／低刺激に限定／医師へ紹介 を選ぶ | 見逃して施術すると**重大インシデント**（信頼度 −30） |
| 2. 触診 | 押しながら脊柱をなぞり、可動性が低く緊張が高いセグメントを特定 | 隣接なら減点、離れると効果なし。長すぎると患者の忍耐が尽きる |
| 3. テクニック選択 | 年齢・骨密度・妊娠・椎間板の状態に合ったテクニックを選ぶ | 骨粗鬆症に強いHVLA等は有害事象に直結 |
| 4. コンタクト & ドライブライン | 触れる骨のランドマークを選び、力を加える方向を矢印で合わせる | 反対側に触れると大きく減点 |
| 5. プリロード & スラスト | 長押しで組織の遊びを取り緑の帯で離す → 呼気の終わりに短く鋭くタップ | 浅い＝空振り、深い＝痛み |
| 6. アフターケア | その患者に合ったセルフケア指導を2つ選ぶ | 安静・コルセット常用などの不適切な指導は減点 |

操作は マウス／タッチ／<kbd>Space</kbd> に対応。スマートフォンの縦画面でも遊べます。

### 手技のキモ

- **HVLA = 高速・低振幅**。スラストは「短く鋭いタップ」が最高評価、押し込むほど振幅過大と判定されます。
- **プリロード**は足りないとキャビテーションが起きず、取りすぎると患者が力みます（防御メーターが上がる）。
- **呼気終末**にスラストを合わせると患者の防御が最小になります。

### 難易度

| | 触診ノイズ | 触診の制限時間 | プリロード帯 | タイミング許容 | ドライブ許容 | ヒント |
|---|---|---|---|---|---|---|
| 初級 | 小 | 34秒 | 48–86 | ±260ms | ±40° | あり |
| 標準 | 中 | 26秒 | 56–80 | ±180ms | ±26° | なし |
| 上級 | 大 | 20秒 | 62–75 | ±120ms | ±16° | なし |

## 収録患者（12人／1日5人をランダム抽出、レッドフラッグを必ず1〜2人含む）

**通常症例** — 頸部痛（C5）、上部胸椎痛（T4）、胸椎の伸展制限（T7）、頸原性頭痛（C2）、仙腸関節痛（SI）

**イエローフラッグ（施術可・低刺激に限定）**
- 骨粗鬆症の高齢者 → アクティベータ／ドロップテーブル
- 急性椎間板障害の神経根症 → フレクション・ディストラクション
- 妊娠32週 → 側臥位での低刺激

**レッドフラッグ（施術せず紹介が正解）**
- 転移性脊椎腫瘍の疑い（癌既往＋体重減少＋夜間痛）
- 椎骨脳底動脈不全の疑い（頸椎回旋で誘発されるめまい・複視・構音障害）
- 馬尾症候群（サドル麻痺＋膀胱直腸障害＋両下肢の進行性筋力低下）
- 脊椎感染症の疑い（発熱＋限局した叩打痛＋免疫抑制状態）

## 実装メモ

単一ファイル（`index.html`）に UI・ロジック・描画・音を同居させています。

- `SPINE` — C1〜仙腸関節までの26セグメント定義。`spineLayout()` が高さに応じて座標を生成し、
  `drawVertebra()` が椎体・横突起・棘突起・関節面を描く。タイトル画面は同じレイアウトを90°回転して使用。
- `Palp` — ガウス分布で「固着」をモデル化。可動性／緊張／圧痛の3メーターに難易度依存のノイズを載せる。
- `Contact` — ランドマーク座標は描画椎骨の幅・高さに対する比率で定義。ドライブラインは角度差の最小値で採点。
- `Thrust` — 呼吸曲線 `breathY()` の谷（phase 0.97）が呼気終末。タップの押下時間がそのまま振幅スコアになる。
- `Result` — 9項目の重み付き平均。有害事象で 0.55 倍、患者の防御が高いと 0.94 倍。
- `Snd` — WebAudio でその場合成。`crack()` はノイズ→バンドパス掃引＋低域サイン。

ベストスコアのみ `localStorage`（`bokiboki_best`）に保存します。

### 動作確認

Playwright（Chromium）で全フェーズを操作するシナリオテストを実施済み。
3難易度 × 2日分（30患者）のランダム通しプレイでコンソールエラーなし、
モバイル幅（390px）で横スクロールが発生しないことも確認しています。
