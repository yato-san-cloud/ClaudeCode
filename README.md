# 方向転換トレーナー（右バック）

教習所の「方向転換（右バック）」の**切り始めの基準点**と**進入の軌跡**を、
スマホ／PCのブラウザで反復練習するための1ファイル簡易シミュレータ。

> 目的は「早切りの矯正」と「切り返しの判断」を安全に何度も試すこと。
> ハンドルを回す腕の速さやクラッチ感といった“操作の体の動き”は実車練習で補う前提。

## 使い方

`index.html` をブラウザで開くだけ（インストール・ビルド不要）。

- **前進 D / 後退 R**：押している間だけ微速で進む
- **左 / 右**：押している間ハンドルを切る（`まっすぐ`で戻す）
- お手本ON：理想の軌跡と「切り始めライン」を表示
- ミラーON：右ミラーに映るポールの見え方（模式）と「切る」タイミングを表示

流れ：**前進で青ラインまで → 止まって、後退＋右いっぱい → ポケットへ**。
後退中に半分以上切った瞬間の位置を見て「早切り／行き過ぎ」をフィードバックします。

## 本人仕様への差し替え

冒頭の `CONFIG` だけ変更すれば、教習車・コースに合わせられます。

```js
const CONFIG = {
  car:    { length, width, wheelbase, frontOverhang, maxSteerDeg, ... },
  course: { laneWidth, bayWidth /*間口*/, bayDepth /*奥行き*/ },
};
```

- 車：マツダ アクセラ セダン（BM/BY型）のカタログ値を初期値に設定済み
- コース：**現在は仮の標準値**。三島中央自動車学校の方向転換枠の実寸（間口・奥行き）が分かり次第差し替え

## 設計メモ

- 物理：自転車モデル（アッカーマン近似）。低速の幾何・軌跡には十分
- 幾何：**お手本の円弧を先に物理計算し、その着地点に枠を配置**することで「解ける幾何」を保証
- 検証：ヘッドレスChromiumで「お手本経路が走行可能領域を出ない」「推奨テクニックで正着する」を自動チェック
