# 教習所トレーナー（方向転換・縦列）

卒検で崩れやすい **方向転換（右バック／左バック）** と **縦列駐車** の
「切り始めの基準点」「進入の軌跡」「切り返しの合図」を、
スマホ／PCのブラウザで反復練習するための1ファイル・モックアップ。

> ねらいは「早切りの矯正」と「切り返しの判断」を安全に何度も試すこと。
> ハンドルを回す腕の速さやクラッチ感といった“操作の体の動き”は実車練習で補う前提。

## 使い方（横向き・運転席モード）

`index.html` を**横向き（ランドスケープ）**で開く。両手で持って**両親指で操作**するゲームHUD配置：

- **画面いっぱい＝俯瞰図**：コース・お手本の軌跡・切り始めの目安ライン・**4輪の動的タイヤ予測線**（ハンドルに追従）・ポール・縁石・コース上の「今！」合図
- **右下＝シフト(P/R/N/D)＋ハンドル（右親指）**：ハンドルは指でドラッグして回す（微調整可・**ロック2.5回転**）。手のアイコンが追従し、大きく切ると持ち替え。`まっすぐ`で中央へ。シフトはハンドルのすぐ隣
- **左下＝ブレーキ／アクセル（左親指）**
- **上＝左右ミラー・速度(km/h)・ギア**。ミラーは後方の景色（ポール・縁石・駐車車両・自車の後輪）を簡易3Dで表示、**ドラッグで角度調整**
- **クリープ**：ONならブレーキを離すと微速で進む。**左親指でブレーキを踏んだまま右親指でシフト→ハンドル**の分担運転が可能。止めて休みたい時は**Pに入れればブレーキを離しても停止**したまま

流れ：Dで目安ラインまで→ブレーキで止める→Rにしてハンドルを切りながら後退→ポケット／スロットへ。
片手なら「クリープON＋ブレーキで微調整」が楽です。

## 本人仕様への差し替え

冒頭の `CONFIG` だけ変更すれば、教習車・コースに合わせられます。

```js
const CONFIG = {
  car:      { length, width, wheelbase, frontOverhang, maxSteerDeg, ... },
  perp:     { bayWidth /*間口*/, bayDepth /*奥行き*/, turninX },
  parallel: { approachY, turninX, theta1Deg, slotDepth, parkedLen, parkedW, ... },
};
```

- 車：マツダ アクセラ セダン（BM/BY型）のカタログ値を初期値に設定
- コース：**現在は仮の標準値**。三島中央自動車学校（MCDS）の実寸が分かり次第差し替え

## 設計メモ

- 物理：自転車モデル（アッカーマン近似）。低速の幾何・軌跡には十分
- 幾何：**お手本の軌跡を先に物理計算し、その着地点に枠を配置**して「解ける幾何」を保証
  - 方向転換：フルロック後退の1円弧／縦列：右→左のS字（2円弧）
  - 縦列の前後の車は「スイング包絡線＋余裕」に配置し、成功枠は車体ぴったりに分離
- 左バックは右バックの左右反転（幾何とお手本を y 反転して生成）
- 検証：ヘッドレスChromiumで、各課題「お手本経路が走行可能領域を出ない」「終端で枠に正着」を自動チェック
