# ヒマ神 🎮 — くそ面白いミニゲーム集

スマホで遊べる、ヒマつぶし特化のミニゲーム集アプリ。
インストール不要のWebアプリ（PWA）で、ホーム画面に追加すればネイティブアプリみたいに遊べます。オフラインでも動きます。

## 収録ゲーム

| ゲーム | 内容 | 使う機能 |
|--------|------|----------|
| ⚡️ 反射神経テスト | 画面が緑になった瞬間にタップ。反応速度(ms)を計測 | タッチ・バイブ |
| 🔥 連打スピード | 5秒間で何回タップできるか | タッチ・バイブ |
| 🎰 運命のガチャ | 今日の運勢をレア度で占う（SSS〜Z） | バイブ・演出 |
| 📢 叫びメーター | マイクに叫んで音量メーターを振り切れ | マイク |
| 📱 シェイクバトル | 10秒でスマホを何回振れるか | 加速度センサー |
| 🧠 記憶ヘビ | 光る順番を覚えて再現するサイモン風ゲーム | タッチ・記憶 |

- ハイスコアは端末に自動保存（localStorage）
- 全ゲーム共通で振動・紙吹雪・サウンドレスな軽快UI

## 遊び方（ローカル）

ただのHTML/CS/JSなので、簡易サーバーで開くだけ。
マイク・センサー機能は **HTTPS か localhost** が必要です。

```bash
# Python があれば
python3 -m http.server 8000
# → スマホで http://<PCのIP>:8000 を開く（同一Wi-Fi）
```

または `index.html` をブラウザで直接開いてもタッチ系ゲームは動きます。

## スマホに「アプリとして」入れる

1. 上記サーバー（またはGitHub Pages等のHTTPS）でサイトを開く
2. ブラウザのメニューから **「ホーム画面に追加」**
3. アイコンから起動するとフルスクリーンのアプリ体験に

## 技術

- 依存ライブラリゼロ（Vanilla JS）
- PWA: `manifest.webmanifest` + Service Worker (`sw.js`) でオフライン対応
- Web Audio API（叫びメーター）/ DeviceMotion API（シェイク）/ Vibration API

## ファイル構成

```
index.html              画面とゲームカード
style.css               スタイル（ダーク＆ネオン）
app.js                  全6ゲームのロジック
manifest.webmanifest    PWA設定
sw.js                   オフラインキャッシュ
icon.svg                アプリアイコン
```
