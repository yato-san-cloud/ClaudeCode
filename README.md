# ボキボキ・クリニック

**カイロプラクティック・アジャストメント シミュレーター**

「手術シミュレーター」的なノリで、カイロプラクターのアジャストメント（矯正）を
一連の流れとして体験できるブラウザゲームです。
依存ライブラリなし・外部アセットなしの単一 HTML ファイルで動きます。

```
open index.html      # ブラウザで開くだけ
```

ビルド・インストール・サーバ不要。描画はすべて Canvas、効果音はすべて WebAudio で合成しています
（「ポキッ」というキャビテーション音もノイズバースト＋バンドパスで生成）。

## 遊びかた

1日5人の患者を担当し、患者ごとに次の6フェーズを進めます。

| フェーズ | やること | 失敗すると |
|---|---|---|
| 1. 問診・スクリーニング | 病歴と所見からレッドフラッグを探し、施術／低刺激に限定／医師へ紹介 を選ぶ | 見逃して施術すると**重大インシデント**（信頼度 −30） |
| 2. 触診 | 押しながら脊柱をなぞり、可動性が低く緊張が高いセグメントを特定 | 隣接なら減点、離れると効果なし。長すぎると患者の忍耐が尽きる |
| 3. テクニック選択 | 年齢・骨密度・妊娠・椎間板の状態に合ったテクニックを選ぶ | 骨粗鬆症に強いHVLA等は有害事象に直結 |
| 4. コンタクト & ドライブライン | 触れる骨のランドマークを選び、力を加える方向を矢印で合わせる | 反対側に触れると大きく減点 |
| 5. プリロード & スラスト | **施術台の患者の体**にあなたの手が置かれる。コンタクト点を掴んで矢印の向きへ引き、呼気の終わりに短く鋭く弾く | 遅い＝空振り、深い＝痛み、深すぎ＝重篤 |
| 6. アフターケア | その患者に合ったセルフケア指導を2つ選ぶ | 安静・コルセット常用などの不適切な指導は減点 |

操作は マウス／タッチ／<kbd>Space</kbd> に対応。スマートフォンの縦画面でも遊べます。

### フェーズ5は「実際に触る」画面です

施術台にうつ伏せで寝た患者が、対象部位に寄った状態で表示されます。首なら首、腰なら腰。
皮膚の下に脊柱が透けて見え、狙うセグメントだけが光ります。体は呼吸で上下し、
あなたの手（豆状骨コンタクトと支持手）はフェーズ4で選んだランドマークの上に置かれています。

操作は抽象的なゲージではなく、**その手を実際にドラッグする**ことです。

1. **掴んで引く** — コンタクト点を押さえ、矢印（＝フェーズ4で決めたドライブライン）の向きへ引く。
   引くほど組織がへこみ、皮膚が引かれ、対象の椎骨が動きます。緑の帯まで引けばスラック確保。
2. **弾く** — 呼気の終わりに、そのまま**短く鋭く弾く**。

弾きの速さと距離をそのまま測っています。

| 測定値 | 意味 | 良い値 |
|---|---|---|
| スラスト速度 | フレーム間の瞬間速度（px/秒） | 速いほど良い（HVLA の H） |
| 振幅 | 弾き始めから止まるまでに進んだ距離（px） | 浅いほど良い（HVLA の LA） |

**速く・浅く**の両立が難しいのがこの手技の本体です。ゆっくり押し込んでも「押しているだけ」で
スラストとして検出されず、関節は動きません。逆に勢い任せに深く突っ込むと
振幅が伸び、**貫通ラインを越えた瞬間に重篤な有害事象**として確定します（離すのを待ちません）。

トグルリコイルはさらに、弾いたあと**引き戻す**動作そのものがリコイルとして採点されます。

<kbd>Space</kbd> でも操作できます（長押しでスラック → 離して固定 → 短くタップ）。
この場合は押していた時間が速度と振幅に、短く離したことがリコイルに換算されます。

- **プリロード**は足りないとキャビテーションが起きず、取りすぎると患者が力みます（防御メーターが上がる）。
- **呼気終末**にスラストを合わせると患者の防御が最小になります。
- スラストに至らないまま3回手を離すか、体位を保てる42秒を過ぎると施術は中断されます。

## 練習モード

本番は1患者につき1回きりで、失敗はそのまま信頼度に響きます。手技を体に入れる場所として、
タイトル画面と一日の終わりから**練習モード**に入れます。スコアにも信頼度にも影響しません。

| ドリル | 内容 | 合格条件 |
|---|---|---|
| 触診 | 押しながらなぞって固着セグメントを当てる | ズバリ的中 |
| コンタクト & ドライブライン | ランドマークと駆動方向を合わせる | 両方そろう |
| スラスト | 施術台で実際に弾く | キャビテーションが出る |
| ガンステッド分析 | ノビスコープ走査 → X線リスティング | ブレイクもリスティングも正解 |
| トグルリコイル | アトラス読影 → 環椎を弾いて戻す | 貫通させずに抜ける |

失敗するたび、**どこがどう足りなかったかを数値で**返します。たとえばスラストなら：

```
✘ プリロード 42点 — 緑の帯（56〜80）で止めてから弾いてください
✔ タイミング 呼気終末から 96ms（許容 ±180ms）
✘ スラスト速度 480px/秒（700未満はスラスト不成立、1900で満点）— もっと鋭く
✔ 振幅 31px（58px 以内が満点）
```

<kbd>Enter</kbd> または「もう一度」で即やり直し。連続合格数を記録し、自己最高が残ります。
補助として**正解ガイドの常時表示**（上級でもヒントを出す）と、
**呼吸をゆっくりに**（周期を4秒→6.6秒に伸ばしてタイミングだけ練習する）を切り替えられます。

## 本格派の2ルート

テクニック選択の結果によって、フェーズ4以降が丸ごと差し替わります。

### ガンステッド・システム

このシステムの本体は**分析の厳密さ**なので、コンタクトの前に2工程が挟まります。

**① ノビスコープ（皮膚温左右差の計測）**
二又プローブを棘突起の両脇に当て、上から下へ滑らせて皮膚温の左右差を記録します。
速度は時間窓で測っており、上限（初級340／標準260／上級190 px/秒）を超えた区間は
**記録されずトレースに穴が空きます**。走査後、記録されたトレースから
**ブレイク**（急な振れ）をクリックして読み取ります。
ここが挽回ポイントで、**触診より正確に当てられれば触診の所見が上書きされます**。

**② X線リスティング**
正面像で棘突起の偏位側（**R/L**）、側面像で棘突起先端の向き（**S/I**）を読み、
`P＋R/L＋S/I＋接触構造` のリスティングを確定します（骨盤は `PI＋左右`）。

リスティングが決まれば、コンタクトとドライブラインは**機械的に決まります**。

> 接触＝棘突起が偏位した側の構造（接尾辞が構造を示す。-sp 棘突起／-la 椎弓板／-m 乳様突起／-t 横突起／-pil 関節柱）
> 駆動＝偏位の逆向き。R→患者の左、L→患者の右、S→尾側、I→頭側

つまり**読影を誤れば、そのまま逆側に組み立ててしまいます**。正解は自分が確定した
リスティングではなく真のリスティングから採点されるので、誤りはそのまま設定ミスとして返ってきます。
スラストは**ボディドロップ**で、スラック帯・タイミング・振幅すべての判定が通常より狭い代わりに、
リスティングを当てて走査も十分なら精度ボーナスがつきます。

### トグルリコイル（上位頸椎専用）

対象が **C1・C2** のときだけ選択肢に現れます。

**① アトラス・リスティング** — 開口位正面像で、歯突起と外側塊の間隙が狭い側（ラテラリティ）と、
横突起が中間位より高いか低いか（S/I）を読み、**AS/AI＋R/L** を確定します。

**② スタック → トグル → リコイル**

1. **スタック** — 長押しで手首を積む。3つのリングが重なった瞬間に離す。
2. **トグル** — 呼気の谷でタップ。
3. **リコイル** — ここが本番。**押した瞬間から到達深度が跳ね上がります**（0.30／ms）。
   緑の帯（標準30〜54）で離せば成功、**赤い貫通ライン（標準64）に触れたら重篤な有害事象**です。

標準難易度なら、適正深度に収まるのは押下 **100〜180ms**、貫通は **213ms**。
猶予は 80ms、そこから事故まではさらに 33ms しかありません。
環椎の裏には環軸関節・椎骨動脈・上位頸髄があります。深く入れるのではなく、
**触れた瞬間に跳ね返る**。関節を動かすのは深さではなく速さです。

貫通させると患者はその場で救急搬送、スコア0・信頼度−40。ここだけは他の失敗と桁が違います。

| | 触診ノイズ | 触診の制限時間 | プリロード帯 | タイミング許容 | ドライブ許容 | ヒント |

| 初級 | 小 | 34秒 | 48–86 | ±260ms | ±40° | あり |

## 収録患者（13人／1日5人をランダム抽出、レッドフラッグを必ず1〜2人含む）

**通常症例** — 頸部痛（C5）、上部胸椎痛（T4）、胸椎の伸展制限（T7）、頸原性頭痛（C2）、仙腸関節痛（SI）、環椎の左方変位（C1／トグルリコイル適応）

**イエローフラッグ（施術可・低刺激に限定）**
- 骨粗鬆症の高齢者 → アクティベータ／ドロップテーブル
- 急性椎間板障害の神経根症 → フレクション・ディストラクション
- 妊娠32週 → 側臥位での低刺激

**レッドフラッグ（施術せず紹介が正解）**
- 転移性脊椎腫瘍の疑い（癌既往＋体重減少＋夜間痛）
- 椎骨脳底動脈不全の疑い（頸椎回旋で誘発されるめまい・複視・構音障害）
- 馬尾症候群（サドル麻痺＋膀胱直腸障害＋両下肢の進行性筋力低下）
- 脊椎感染症の疑い（発熱＋限局した叩打痛＋免疫抑制状態）

## 実装メモ

単一ファイル（`index.html`）に UI・ロジック・描画・音を同居させています。

- `SPINE` — C1〜仙腸関節までの26セグメント定義。`spineLayout()` が高さに応じて座標を生成し、
  `drawVertebra()` が椎体・横突起・棘突起・関節面を描く。タイトル画面は同じレイアウトを90°回転して使用。
- `Palp` — ガウス分布で「固着」をモデル化。可動性／緊張／圧痛の3メーターに難易度依存のノイズを載せる。
- `Contact` — ランドマーク座標は描画椎骨の幅・高さに対する比率で定義。ドライブラインは角度差の最小値で採点。
- `Body` / `bodyLay` — 縦1000の正規化座標に全身を組み、`camera()` で対象部位へ寄せる。
  シルエットは同じ形状群を「一回り大きい暗色」→「肌色」の順に二度描いて輪郭を出している
  （個々の図形を stroke すると内側の継ぎ目が出るため）。脊柱は `bodyLay` 上に `drawVertebra()` で描画。
- `Thrust` — 施術台の本体。ポインタの変位をドライブベクトルへ射影した値がスラック、
  **フレーム間の瞬間速度**が閾値を超えた時点をスラスト開始とみなし、そこからの到達距離が振幅。
  貫通ラインを越えた時点で離すのを待たず `resolve()` する。`mode` で normal / gonstead / toggle を切り替え、
  ガンステッドはスラック帯・タイミング窓・振幅窓を一括で絞る。中断3回または42秒で `giveUp()`。
- `Nervo` — 走査速度は**170msの時間窓**で算出し、ポインタイベントの発火間隔に依存させない。
  記録は「前フレームの位置から現在位置までの区間をまとめて埋める」方式なので、フレーム落ちで穴が開かない。
- `Listing` / `Atlas` — 模式レントゲンを Canvas で生成。患者データの `gs` / `atlas` から
  棘突起の偏位・先端の傾き・外側塊の間隙・横突起の高さを描き分ける。
  `gsDerive()` / `atDerive()` がリスティングからコンタクトと駆動角を機械的に導出する。
- `Toggle` — 押下中に深度が 0.30／ms で上昇し、貫通ラインを越えた瞬間に `draw()` 内から
  `resolve()` を強制発火させる（離すのを待たない）。
- `Result` — 最大13項目の重み付き平均（存在するキーだけで正規化するので、ルートごとに項目数が変わる）。
  関節が動かなければ 0.78 倍、有害事象で 0.55 倍、重篤事故は 0 点。
  ガンステッド／トグルを読影から完遂すると 1.03 倍。
- `Practice` — 本編の各フェーズをそのまま単体で回す。フェーズ完了地点は
  `Practice.next(次へ進む関数, 工程名)` を経由しており、練習中でなければ本編どおり進む。
  練習用の `S.p` / `S.cur` を毎回組み直し、そこまでの工程は正解済みとして埋める。
  講評は本編と同じ採点値から、閾値と実測値を並べて生成する。
- `Snd` — WebAudio でその場合成。`crack()` はノイズ→バンドパス掃引＋低域サイン。

`localStorage` に保存するのはベストスコア（`bokiboki_best`）と
練習ドリルごとの最高連続合格数（`bokiboki_prac`）だけです。

### 動作確認

Playwright（Chromium）で全フェーズを操作するシナリオテストを実施済み。
3難易度 × 2日分（30患者）のランダム通しプレイでコンソールエラーなし、
モバイル幅（390px）で横スクロールが発生しないことも確認しています。
ガンステッドは分析工程込みで実走、トグルリコイルは読影から施術台まで通しで確認しています。
フェーズ5はポインタのドラッグ＋フリックを実際に合成して、
「良いフリック＝キャビテーション」「押し込みすぎ＝重篤」「速度不足＝スラスト不成立」
「中断3回で決着」「キーボード経路」の各分岐を検証済みです。
練習モードは5ドリルすべてを合格・不合格の両方で回し、やり直しで状態が持ち越されないこと、
本編へ戻ると練習状態が消えることまで確認しています。
