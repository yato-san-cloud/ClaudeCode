# gen_schedule — タスク表1枚からガント一式を自動生成

構想の背景と全体像は `docs/スケジュール管理_構想.md` を参照。
gen_knowledge.py の兄弟スクリプト（正はデータ、見た目は生成）。

## 使い方

```bat
python gen_schedule.py ローソン立上げ_tasks.csv --out "(OneDrive同期フォルダ)\スケジュール"
```

- `--today 2026-07-17` … テスト用に「今日」を固定できる
- 再実行するたびに全出力を上書きし、前回との差分を `変更履歴.md` に自動追記する

## 入力: タスク表の列仕様（CSV UTF-8 / xlsx 可）

| 列 | 必須 | 内容 |
|---|---|---|
| ID | ○ | 一意の番号（例: S-01）。変更履歴の追跡キーなので途中で変えない |
| 大項目/中項目/小項目 | 大のみ○ | WBS 階層。ガントの行グループは大項目単位 |
| 担当正/担当副 | 正のみ○ | 部署または氏名（例: [静東]、支援者） |
| 開始日/終了日 | ○ | YYYY-MM-DD |
| 状態 | ○ | 未着手 / 着手 / 完了 の3値のみ |
| マイルストーン | | 任意の値が入っていれば ◆ 表示（終了日の週） |
| 先行ID | | 依存タスクの ID（v1 は表示のみ。ツールチップに出る） |
| 進捗メモ/備考 | | 自由記述 |

## 出力

| ファイル | 用途 |
|---|---|
| `<名前>_ガント.xlsx` | 現行様式の週次ガント（□=予定 ■=実施 ☆=完了 ◆=MS、今日の週に色）。定例会・印刷用 |
| `<名前>_ガント.html` | ブラウザで開くガント。担当フィルタ・今日線・遅延赤枠。Teams 共有用 |
| `スケジュール_最新.md` | 遅延/今週/直近マイルストーンの要約。SharePoint に置けばエージェントの根拠になる |
| `変更履歴.md` | 前回実行との差分（追加/削除/日程変更/状態変更）を日付つきで自動追記 |
| `.snapshot.json` | 差分検出用の内部ファイル。消すと次回が「初回登録」になる（消してよい） |

## サンプル

`ローソン立上げ_サンプル.csv`（FFL の大日程をローソン仮日程で再構成した 18 タスク）と
その出力一式が `demo/` にある。まず HTML をブラウザで開くと動きが分かる。

## 運用ルール

1. 人が編集するのはタスク表だけ。出力ファイルは直接編集しない（次回実行で消える）
2. 週次（定例会前）に 1 回実行。定時ジョブに載せる場合は「営業管理_週次」タスクに 1 行追加
3. ID は永久欠番方式（削除しても再利用しない）。行の削除より状態や備考で残す方が履歴が読める
