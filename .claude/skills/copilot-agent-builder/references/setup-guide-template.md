# 配備ガイド雛形（エージェントごとに生成して渡す）

スキルはこの雛形の `{ }` をすべて実際の値で埋めた `setup-guide-<agent-slug>.md` を
生成する。**ユーザーがこのガイドだけを見て、何も考えずに配備を完了できる**ことが合格基準。
「〜を適宜設定」「〜など」という書き方は禁止。全欄について貼る文字列そのものを載せる。

# 配備ガイド: {エージェント名}

所要時間の目安: 15分（うち待ち時間 5〜10 分）

## STEP 1: HTML ファイルを SharePoint に置く（5分）

1. ブラウザで SharePoint サイト `{サイト名/URL}` を開く
2. ドキュメントライブラリ `{ライブラリ名}` を開く（なければ「+新規」→「フォルダー」で
   `copilot-skills` を作る）
3. 「アップロード」→「ファイル」で以下をすべて選んでアップロードする:

| # | ファイル名 | 中身（h1 タイトル） | エフォート |
|---|---|---|---|
| 1 | {skill-xxx.html} | {スキル: 〇〇} | {deep/standard/light} |

4. **権限確認**: ライブラリの「…」→「アクセス許可の管理」を開き、このエージェントを
   使う人全員に閲覧権限があることを確認する（権限がない人にはナレッジが効かない）

## STEP 2: エージェントを作成する（5分）

1. ブラウザで `https://m365.cloud.microsoft/chat` を開く（または Teams の Copilot）
2. 右側ペインの「エージェント」→「**エージェントを作成する**」をクリック
3. 「**構成**」タブに切り替える（「説明」タブの対話形式は使わない。構成タブに直接貼る方が確実）
4. 各欄に下の表の内容を**そのまま**貼り付ける:

| 画面の欄 | 貼り付ける内容 |
|---|---|
| 名前 | {エージェント名} |
| 説明 | {1〜2 文の説明} |
| 指示 | 下の「指示欄の全文」をすべてコピーして貼る |
| 会話のきっかけ（スターター） | ① {スターター1} ② {スターター2} |

### 指示欄の全文（ここから下をコピー）

```
{生成した instructions 全文。8,000 字以内であることを検証済みの状態で埋め込む}
```

## STEP 3: ナレッジを登録する（2分）

1. 同じ「構成」タブの「**ナレッジ**」セクションで「SharePoint」を選ぶ
2. 検索欄に `{ライブラリ名}` または各ファイル名を入力し、STEP 1 で
   アップロードしたファイル（またはフォルダごと）をすべて選択する
3. 「Web コンテンツ」等の他ソースは**オフのまま**にする（社内手順以外から回答させないため）

## STEP 4: 公開して動作確認する（待ち時間込み 5〜10分）

1. 右上「**作成**」を押す → 公開範囲は `{自分のみ/共有}` を選ぶ
2. **5 分待つ**（ナレッジのインデックス作成に数分かかる。直後に試すと
   「見つからない」と答えるが故障ではない）
3. エージェントとのチャットで以下を 1 つずつ投げ、期待どおりか確認する:

| # | テスト質問 | 期待する挙動 |
|---|---|---|
| 1 | {文書名を含む質問} | 文書「{h1 タイトル}」を根拠に回答する |
| 2 | {文書名を含まない言い回し} | 同じ文書に正しくルーティングされる |
| 3 | {対象外の依頼} | 対応可能な依頼一覧を案内する（推測で答えない） |

## 更新のしかた（運用開始後）

- **手順を変えたいとき**: SharePoint 上の該当 HTML を上書きするだけ。
  エージェント側の操作は不要。反映まで数分
- **業務を追加したいとき**: Claude で新しい HTML を生成 → STEP 1 でアップロード →
  エージェントの「編集」で指示欄の Routing に 1 行追加 → ナレッジにファイルを追加

## うまく動かないとき

| 症状 | 原因と対処 |
|---|---|
| 「情報が見つからない」と答える | インデックス未完了（数分待つ）/ 権限不足（STEP 1-4 を確認） |
| 手順書と違う答えを返す | Routing のタイトルと HTML の h1 が不一致 → 完全一致させる |
| 一般知識で勝手に答える | 指示欄の Error handling が消えていないか確認。それでも直らない場合はエージェントビルダーの仕様上、完全遮断は不可 |
