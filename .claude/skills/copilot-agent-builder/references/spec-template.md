# 仕様書（spec.md）雛形

スキルはこの雛形の `{ }` をすべて実際の値で埋めた `agents/CPA-NNN-<slug>/spec.md` を
生成する。`{ }` を空欄のまま渡すことは禁止。特に「背景（Why）」セクションと
「変更履歴」表の理由（Why）列は、ヒアリングで得た具体的な事実（困りごと・頻度・
きっかけ）から書くこと。数値や頻度が聞き出せていない場合はヒアリングに戻って
確認し、仮の値で埋めない。「適宜」「など」「必要に応じて」は使わない。
