# 議事録Skill

文字起こし全文から、配布可能な品質の議事録**ドラフト**を作る。正本化(docx変換・配布)は人間の判断。

## 入力

1. 文字起こし全文(md/docx/txt。Driveの場合は読み取りのみ)
2. 会議メタ情報: 日時・形式・出席者・配布先(文字起こし冒頭から拾えれば確認のみ)
3. 任意: 前回議事録・関連論点表(継続論点のステータス引継ぎ用)

入力が足りないとき: 文字起こしが無ければ停止せず「メモ書きからの簡易議事録になる」と明示して進める。出席者名が不明な発言は「(発言者不明)」とし、推測で人名を割り当てない。

## 手順

1. **発言者の正規化**: 文字起こしの表記ゆれ(氏名/ローマ字/敬称)を統一。社外者は「様」、社内は「さん」。
2. **行番号(L番号)の付与**: 引用の根拠に使うため、文字起こしに通し番号を振る(既にあればそれを使う)。
3. **論点抽出**: 議題ではなく「対立・確認・決定が発生した単位」で論点を切る。
4. **分類**: 各論点にステータスを付ける — 〔クローズ〕〔継続〕〔条件付き〕〔決定〕。条件付き合意は**条件を明文化**する。
5. **発言要旨の引用**: 重要発言は「」で要旨化し、L番号を付ける(例: 「現状通りなら改修不要」L482)。要約と発言の混同を防ぐ。
6. **宿題抽出**: 担当(社名/氏名)・期日・成果物を表に。期日未言及は空欄+**みなし確定条項**(「YYMMDDまでに異議なければ確定扱い」)を提案。
7. **サマリ作成**: 決定事項→残論点→次アクションの順で冒頭に。

## 出力フォーマット

```markdown
# 議事録：(案件名)◯◯の件

| 項目 | 内容 |
|---|---|
| 日時 | YYYY年M月D日(曜) HH:MM〜HH:MM(約X時間) |
| 形式 | Web会議/対面 |
| 出席者 | 先方: ◯◯様 ほか ／ 当社: ◯◯、◯◯ ほか |
| 作成 | 会社名 氏名(作成日) |
| 配布先 | 出席者、関係上長 |

## 1. サマリ
## 2. 決定事項(D-1〜)
## 3. 論点(各ステータス〔クローズ/継続/条件付き/決定〕、発言要旨「」+L番号付き)
## 4. 宿題(H-1〜: 内容/担当/期日/成果物。みなし確定条項付き)
## 5. 次回・次アクション
```

ファイル名: `MMDD_内容_議事録_v1.md`(運用ルール `docs/02` 準拠)

## 禁止事項・安全

- **人物評・交渉戦術・社内事情は議事録に書かない**。気づいた点は別途「🔒私的メモ候補」として本文外(チャット)で伝える
- 文字起こしに無い合意を書かない。推測が必要な箇所は〔要確認〕マークを付けて人間に委ねる
- 既存議事録ファイルを上書きしない。常に新規ファイル(次版番号)として出力
- 配布・送付はしない。「ドラフト完成。docx正本化と配布前チェック(`templates/配布前チェックリスト.md`)はユーザー側で」と締める

## 完了条件

- 全宿題に担当が入っている(不明は〔要確認〕)
- 全論点にステータスが付いている
- 重要な数字・金額にL番号引用が付いている
