# 配備ガイド: 週報ドラフト(静岡営業)

所要時間の目安: 15分（うち待ち時間 5〜10 分）

## STEP 1: ナレッジ配置の前提を確認する（5分）

このエージェントは新しくファイルを SharePoint に配置する作業を必要としない。前提となる配置手順がすでに済んでいるかを確認するだけでよい。

1. `agents/docs/ナレッジ配置手順.md` の「1. サイトとライブラリ」「2. 同期」「3. 台帳スナップショットの自動出力」（手順1〜3）が完了していることを確認する。未完了の場合は、このガイドを進める前にそちらを先に実施する。
2. このエージェントが参照する4ファイルが SharePoint サイト「営業管理」に配置済みかを、以下の表で1件ずつ確認する。

| # | ファイル名 | 配置先フォルダ | 区分 | 配置確認 |
|---|---|---|---|---|
| 1 | 週報フォーマット仕様.md | ドキュメント/ナレッジ/01_フォーマット | 静的 | □ |
| 2 | 案件リスト_最新.md | ドキュメント/ナレッジ/02_台帳スナップショット | 動的（gen_knowledge.py の出力） | □ |
| 3 | 活動サマリ_最新.md | ドキュメント/ナレッジ/02_台帳スナップショット | 動的（gen_knowledge.py の出力） | □ |
| 4 | 用語集_営業管理.md | ドキュメント/ナレッジ/00_共通 | 共有（CPA-002・CPA-003 とも共通参照） | □ |

3. **権限確認**: ドキュメントライブラリの「…」→「アクセス許可の管理」を開き、このエージェントを使う静岡営業課の部下・上司全員に閲覧権限があることを確認する（権限がない人にはナレッジが効かない）。

## STEP 2: エージェントを作成する（5分）

1. ブラウザで `https://m365.cloud.microsoft/chat` を開く（または Teams の Copilot）。
2. 右側ペインの「エージェント」→「**エージェントを作成する**」をクリックする。
3. 「**構成**」タブに切り替える（「説明」タブの対話形式は使わない。構成タブに直接貼る方が確実）。
4. 各欄に下の表の内容を**そのまま**貼り付ける。

| 画面の欄 | 貼り付ける内容 |
|---|---|
| 名前 | [CPA-001] 週報ドラフト(静岡営業) |
| 説明 | 今週の活動記録から静岡営業課の週報ドラフトを標準フォーマットで作成します。活動メモの貼り付けでも、ナレッジの活動サマリからでも作れます。 |
| 指示 | 下の「指示欄の全文」をすべてコピーして貼る |
| 会話のきっかけ（スターター） | ①今週の週報ドラフトを作って ②この活動メモから週報の下書きを作って:(ここに貼り付け) ③先週分(M/D〜M/D)で作り直して ④○○社の項だけ書き直して |

### 指示欄の全文（ここから下をコピー）

```
あなたはロジスティード中部・静岡営業課の週報ドラフト作成担当です。営業チームの活動記録から、上司へ提出する週報の下書きを作ります。

# 入力
次のいずれか(併用可):
- ユーザーが貼り付ける今週の活動メモ・活動記録
- ナレッジの「活動サマリ_最新.md」(対象週の指定がなければ直近7日分を使う)
案件の属性(旗艦タグ・受注計上額・ステージ・担当)は必ずナレッジの「案件リスト_最新.md」で照合します。

# 出力フォーマット(週報フォーマット仕様.mdに準拠)
1. 主要案件の進捗 — 旗艦タグ=旗艦 または 受注計上額5百万円/月以上の案件。(1)(2)…の番号付き。
   各案件: 「(n) 取引先「案件名」 担当(氏名)」の見出し行+今週の動き2〜4行+ネクストアクション(期日)。
   進捗の記述は「⇒」で始める現行週報の記法に合わせる。
2. その他進捗状況 — 上記以外のアクティブ案件を①②…で1案件1〜2行。
3. 受注・立上げ — ステージ=L4の案件(取引先/案件名/金額/作業開始/運営部署)。
最後に「■台帳未登録の活動」として、案件リストに存在しない取引先の活動を列挙する(新規リードの登録漏れ検知のため)。

# 厳守する規則
- 事実のみ。貼り付けとナレッジにない情報を創作しない。不明な項目は「(記載なし)」と書く。
- 確度(Z/A/B/C/D)・ステージ(L1〜L4)・商談フェーズ・活動区分は用語集_営業管理.mdの語彙をそのまま使う。言い換えない。
- 文体は簡潔な報告体(です・ます不要、体言止め可)。1文を長くしない。
- 日付は「7/8」形式。金額は「1.2M¥/月」形式。
- 同じ案件の複数活動は1つにまとめ、時系列順に「⇒」でつなぐ。
- 出力の冒頭に「対象週: M/D〜M/D」を明記する。

# ふるまい
- 対象週が曖昧なら最初に1回だけ確認する(それ以外の質問はせず、まず下書きを出す)。
- 下書きを出した後、「不足している案件や直したい表現があれば言ってください。該当箇所だけ修正します」と添える。
- 週報の正式なExcel体裁への転記は人間側の作業(またはgen_weekly.py)。あなたは内容のドラフトに集中する。
```

## STEP 3: ナレッジを登録する（2分）

1. 同じ「構成」タブの「**ナレッジ**」セクションで「SharePoint」を選ぶ。
2. 検索欄で SharePoint サイト「営業管理」内の以下4ファイルを1つずつ検索し、すべて選択する。

| # | ファイル名 | パス |
|---|---|---|
| 1 | 案件リスト_最新.md | ドキュメント/ナレッジ/02_台帳スナップショット/案件リスト_最新.md |
| 2 | 活動サマリ_最新.md | ドキュメント/ナレッジ/02_台帳スナップショット/活動サマリ_最新.md |
| 3 | 週報フォーマット仕様.md | ドキュメント/ナレッジ/01_フォーマット/週報フォーマット仕様.md |
| 4 | 用語集_営業管理.md | ドキュメント/ナレッジ/00_共通/用語集_営業管理.md |

3. 「Web コンテンツ」（Web検索）は**オフのまま**にする（理由: 事実の混入防止）。コードインタープリター・画像生成もオンにしない。

## STEP 4: 公開して動作確認する（待ち時間込み 5〜10分）

1. 右上「**作成**」を押す → 公開範囲は「静岡営業課（部下・上司）」を選ぶ。
2. **5 分待つ**（ナレッジのインデックス作成に数分かかる。直後に試すと「見つからない」と答えるが故障ではない）。
3. エージェントとのチャットで以下を1つずつ投げ、期待どおりか確認する（全項目は `tests.md` に詳細がある）。

| # | テスト質問 | 期待する挙動 |
|---|---|---|
| 1 | 今週の週報ドラフトを作って | 対象週明記＋「主要案件の進捗」「その他進捗状況」「受注・立上げ」の3セクション構成で出力される |
| 2 | 活動サマリにある三生医薬の活動を含めてドラフトを作らせる | 案件リスト_最新.md の属性（確度B・担当）と整合して書かれる |
| 3 | 案件リストにない社名の活動メモを貼って依頼する | 本文3セクションに混ざらず「■台帳未登録の活動」に隔離される |
| 4 | 出力全体を確認する | 貼り付け・ナレッジのいずれにもない事実（受注した等）が書かれていない |

## STEP 5: 稼働開始後の記録（配備完了後に実施）

1. `agents/registry.md` の CPA-001 行の「状態」を稼働中に更新し、「最終更新日」を配備完了日に更新する。
2. パッケージ一式（spec.md／instructions.md／skills/／setup-guide.md／tests.md）を SharePoint の `copilot-agents` ライブラリの `CPA-001_週報ドラフト(静岡営業)` フォルダへ複製保管する。これが `agent-package.md` §5 の規則どおりの正の保管場所になる。全体設計 §5 の「エージェント定義/」フォルダは、Instructions 正本の控え置き場として使ってよいが、パッケージ一式の正の保管先ではない。

## 更新のしかた（運用開始後）

- **静的ナレッジ（週報フォーマット仕様.md）・共有ナレッジ（用語集_営業管理.md）を変えたいとき**: SharePoint 上の該当ファイルを削除してから同じファイル名で再アップロードする。エージェント側の操作は不要。反映まで数分。
- **動的ナレッジ（案件リスト_最新.md・活動サマリ_最新.md）を最新化したいとき**: `gen_knowledge.py` を実行し、OneDrive 同期フォルダの出力先へ上書きする。ファイルの削除・再アップロードは不要（同期フォルダへの上書きだけで SharePoint 側が自動更新される）。
- **指示（Instructions）を変えたいとき**: `agents/CPA-001-weekly-report-draft/instructions.md` を先に更新し、版を上げてから `agent-package.md` の保守モードに従って再設定する。

## うまく動かないとき

| 症状 | 原因と対処 |
|---|---|
| 「情報が見つからない」と答える | インデックス未完了（数分待つ）／権限不足（STEP 1 の権限確認を見直す） |
| 手順書と違う答えを返す | ナレッジの参照ファイルが最新版に置き換わっていない可能性。SharePoint 上のファイルの更新日時を確認する |
| ナレッジがまったく引用されない（判定テスト T1b 不合格） | SharePoint 上の .md ファイルがグラウンディングに使われていない可能性。該当ファイルを .docx に変換して再アップロードし、同じ質問で再確認する |
| 一般知識で勝手に答える | 指示欄の「事実のみ」規則が消えていないか確認する。それでも直らない場合はエージェントビルダーの仕様上、一般知識の完全遮断は不可 |
