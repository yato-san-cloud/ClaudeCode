# 週報フォーマット仕様 — エージェント用ナレッジ

静岡営業課の週報の構成と文体。週報ドラフトエージェントはこの仕様に準拠する。

## 構成(3セクション+付記)

```
静岡チーム 週報  対象週: M/D〜M/D

1. 主要案件の進捗
(1) 取引先「案件名」 担当(氏名)
　⇒ 今週の動き(事実。日付付き)
　⇒ 相手の反応・決定事項
　次: ネクストアクション(期日 M/D)
(2) …

2. その他進捗状況
① 取引先「案件名」(確度C) ⇒ 1〜2行の進捗要約 担当(氏名)
② …

3. 受注・立上げ
・取引先「案件名」 1.2M¥/月 作業開始 25/9 [静東]中部
・…

■台帳未登録の活動(あれば)
・社名: 活動の要約 → 案件登録するか判断してください
```

## 主要案件の基準

旗艦タグ=旗艦、または受注計上額5百万円/月以上。それ以外はセクション2へ。

## 文体規則

- 簡潔な報告体。体言止め可。1文60字以内目安
- 進捗行は「⇒」始まり(現行週報の記法)。時系列に並べる
- 主語は省略可、ただし相手方の発言・決定は「先方より」「○○部長より」と発話者を明示
- 憶測語(〜と思われる、おそらく)は使わない。不確実なら「未確認」「〜との情報(裏取り前)」
- ネガティブ情報(失注リスク・遅延)は隠さずセクション内で先に書く

## 文例(実際の週報の型)

> (3) 富士フイルムロジ「静岡東部地区拠点開設」 担当(八峠)
> 　⇒ 6/3 中村社長・曽我常務がFFL社長と面会し受注ご挨拶を実施。誤出荷ゼロ継続の期待コメントあり
> 　⇒ 封函機設置の最終レイアウトを現場含め検討中
> 　次: 事務作業の1日流れ確認(6/10)、営業部責任者の現場視察(6/11)
