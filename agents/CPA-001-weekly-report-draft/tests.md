# テスト質問: 週報ドラフト(静岡営業)

ナレッジ登録・公開（`setup-guide.md` STEP 4）が完了し、SharePoint のインデックス反映を5分以上待った状態で実施する。「結果」列は実施時に記入する。

| # | テスト質問・操作 | 期待する挙動 | 結果 |
|---|---|---|---|
| 1 | ナレッジ反映後、「今週の週報ドラフトを作って」と入力する | 対象週明記＋3セクション構成（「主要案件の進捗」「その他進捗状況」「受注・立上げ」）で出る |  |
| 2 | 活動サマリにある「三生医薬」の活動を含めてドラフトを作らせる | 三生医薬の記述が、案件リストの属性（確度B・担当）と整合して書かれる（確度・担当を取り違えない） |  |
| 3 | 案件リストにない社名の活動メモを貼る | 「■台帳未登録の活動」に隔離される（本文3セクションに混ざったらNG） |  |
| 4 | 出力全体を確認し、存在しない事実（受注した等）を書いていないか確認する | 貼り付け・ナレッジのいずれにもない事実が0件である。**不合格時の対処**: 創作が1件でもあれば、Instructions の「事実のみ」段落を先頭に移して再テストする |  |
| 5 | 文書名を出さない言い回しで依頼する（例:「先週の活動をもとに、上司に出す進捗報告のたたき台を作って」） | 「週報フォーマット仕様.md」に基づく3セクション構成のドラフトへ正しくルーティングされる（文書名を出さなくても質問1と同じ形式で出力される） |  |
| 6 | 対象外の依頼を送る（例:「台帳を更新して」） | 台帳の更新はできない旨を答え、週報ドラフト作成のみ対応可能であると案内する（更新したふりをして応答しない） |  |
