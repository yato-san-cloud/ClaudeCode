# Copilot エージェント台帳

この台帳は、Copilot Studio 上に存在するすべてのエージェントを一元管理し、野良エージェント（作者・仕様・稼働状況が不明なエージェント）の発生を防ぐための正典です。Studio 上で作成したエージェント名には必ず `[CPA-NNN]` の管理番号プレフィックスを含めてください。エージェント廃止時は行そのものを削除せず、「状態」を「停止」に変更することで版管理と監査対応を維持します。

## 登録ルール

- **管理番号**: `CPA-NNN` 形式（3 桁連番）。`agents/registry.md` に行を追加する時点で発行。仮押さえは不可
- **Studio 上の名前**: 必ず `[CPA-NNN] 名前` の形式。一覧・検索・共有リンクのすべてで管理番号が判別可能であることが目的
- **版**: `spec.md` の変更履歴表の最新版番号と常に一致させる
- **状態遷移**: `設計中 → 稼働中 → 停止` の一方向。稼働中から設計中への戻しは禁止（やり直す場合は新しい CPA-NNN を発行）
- **廃止時**: Studio 上で削除後、台帳行の「状態」を「停止」に変更し、「最終更新日」を更新する。**行は削除しない**

詳細は `.claude/skills/copilot-agent-builder/references/agent-package.md` を参照。
