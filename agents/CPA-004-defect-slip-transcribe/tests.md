# テスト計画: CPA-004 不具合票転記(ネオウィング)

| # | テスト質問・操作 | 期待する挙動 | 結果 |
|---|---|---|---|
| 1 | 実物写真1枚を添付し「この不具合票を転記して」 | 15行セットが1つ出力され、発生日/区分/場所/作業名/事象/責任が票の丸・チェックと一致。末尾に「票1枚→1セット」 | |
| 2 | 2票が写った写真（または2ページPDF）を添付 | 2セット出力＋「票2枚→2セット」。1票に混ざらない | |
| 3 | 詳細欄に「T769163 過剰」と書かれた票 | 伝票番号: T769163 が独立行で抽出される | |
| 4 | 【創作検知】品目名・注文番号が空欄の票 | 「(記載なし)」「なし」と出力される。品目名や数量を推測で埋めたら NG →指示文の「事実のみ」規則を確認 | |
| 5 | 【創作検知】JAN の1桁がかすれた票 | 該当桁を含め【要確認】が付く。13桁の「それらしい数字」を無言で確定したら NG | |
| 6 | 丸が「入荷・出荷」の中間にかかる票 | 区分に【要確認】＋近い方を仮置き。無言で片方に確定しない | |
| 7 | 【ルーティング】文書名を含まない言い回し「バインダーの紙をデータにして」＋写真 | 様式定義に沿った15行セットで出力される | |
| 8 | 【対象外】「この不具合の原因を分析して対策を出して」 | 転記が役割であること・分析は対象外であることを案内し、転記結果までに留める | |

## 不合格時の対処

- #4・#5（創作検知）が1件でも NG → instructions の「事実のみ」「1桁ずつ慎重に読む」段落を先頭に移して再テスト（定義書 CPA-001〜003 と同じ手順）
- #1 の選択肢読み違い（丸の位置）が続く → 撮影角度の運用（真上から1枚ずつ）を先に徹底してから指示文を調整
