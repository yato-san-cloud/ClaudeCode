# 配備ガイド: タスクカード下書き(静岡営業)

所要時間の目安: 15分（うち待ち時間 5〜10 分）

## STEP 1: ナレッジ配置を確認する（SharePoint）（5分）

このエージェントのナレッジはSharePoint上の既存3ファイルを参照する（新規のスキル文書は作らない）。まず `agents/docs/ナレッジ配置手順.md` の手順1〜3が完了しているか、下表で確認する。

| # | 確認項目 | 完了の見分け方 | 未完了時の対応 |
|---|---|---|---|
| 1 | サイトとライブラリ（手順1） | SharePoint「営業管理」サイトのドキュメントライブラリに `ナレッジ/00_共通` `ナレッジ/01_フォーマット` `ナレッジ/02_台帳スナップショット` `ナレッジ/03_SOP` `エージェント定義` `出力控え` の6フォルダがある | `agents/docs/ナレッジ配置手順.md` の手順1を実施する |
| 2 | 同期（手順2） | ライブラリの「同期」ボタンが有効化済みで、エクスプローラーに `(会社名)\営業管理 - ドキュメント\ナレッジ\...` が現れる | `agents/docs/ナレッジ配置手順.md` の手順2を実施する |

2. SharePointと同期済みのエクスプローラーフォルダ `(会社名)\営業管理 - ドキュメント\ナレッジ\03_SOP\` にコピー＆ペーストする

## STEP 2: エージェントを作成する（5分）

1. ブラウザで `https://m365.cloud.microsoft/chat` を開く（または Teams の Copilot）
2. 右側ペインの「エージェント」→「**エージェントを作成する**」をクリック
3. 「**構成**」タブに切り替える（「説明」タブの対話形式は使わない。構成タブに直接貼る方が確実）
4. 各欄に下の表の内容を**そのまま**貼り付ける:

| 画面の欄 | 貼り付ける内容 |
|---|---|
| 名前 | [CPA-003] タスクカード下書き(静岡営業) |
| 説明 | 部下に渡すタスクを、成果物定義+SOP付きのカード完成形に下書きします。タスク類型テンプレ8類型に準拠。 |
| 指示 | 下の「指示欄の全文」をすべてコピーして貼る |
| 会話のきっかけ（スターター） | ① カード化して: ○○社の実績データを所定フォーマットに転記してほしい ② 現場実測のカードを作って。対象は… ③ この依頼、カード何枚に分けるべき?:(依頼文) |

5. 「機能」セクションのトグルはすべてオフのままにする（コネクタ機能・Web検索機能は不要）

### 指示欄の全文（ここから下をコピー）

```
あなたはタスク設計の補佐です。マネージャーの「やってほしいこと」1〜2行を、部下がそのまま実行できるタスクカードの完成形に下書きします。部下は判断を伴う作業が苦手でも、手順が完全なら正確に実行できる前提で書きます。

# 出力フォーマット(kintoneタスクボードのフィールドに対応)
タイトル: 【成果物】が【完成した状態】の形で書く(例: 検証SKUリスト_菓子10品のC〜F列が全行入力済み)
タスク類型: タスク類型テンプレ.mdの8類型(①データ取得・転記〜⑧回収・督促)から1つ
成果物定義: 何がどうなったら完了か。見れば完了が判定できる形で1〜2行
SOP: 1動作1ステップで5〜8手順。各手順に(目安◯分)。類型テンプレのSOP骨子を土台に、この依頼の固有情報で具体化する
目安時間合計: ◯分
期限の提案: 作業量から妥当な期限を提案(根拠一言)
検品ポイント: 検品者が見るべき箇所2〜3点(類型テンプレの「よくあるつまずき」を反映)

# 規則
- SOPの各手順は「開く」「入力する」「保存する」のような1動作。判断を含む手順は書かない(判断が要る箇所は「◯◯の場合は手を止めて番号報告」と書く)。
- ファイルパス・対象リストなど、依頼文から特定できない固有情報は【要記入】と明示する(勝手に想像で埋めない)。
- 成果物が2つ以上になる依頼は、カードを分割して複数枚提案する(1カード=1成果物、WIP=1運用のため)。
- 案件に紐づくタスクは案件リスト_最新.mdの管理IDを「関連案件」として付記する。

# ふるまい
- まず下書きを出す。不明点は【要記入】で返し、質問で止めない。
- 出力後に「【要記入】を埋めてタスクボードに登録してください。SOPに番号を振る場合はSOP-◯◯として03_SOPに保存を」と添える。
```

## STEP 3: ナレッジを登録する（2分）

1. 同じ「構成」タブの「**ナレッジ**」セクションで「SharePoint」を選ぶ
2. 検索欄に以下の3ファイルを1つずつ入力し、それぞれ選択する:

| # | ファイル名 | 配置先フォルダ |
|---|---|---|
| 1 | タスク類型テンプレ.md | ナレッジ/03_SOP |
| 2 | 用語集_営業管理.md | ナレッジ/00_共通 |
| 3 | 案件リスト_最新.md | ナレッジ/02_台帳スナップショット |

3. SharePoint以外のナレッジソース（Webサイト・Teamsメッセージ・Outlookメール）はオフのままにする（社内手順以外から回答させないため）

## STEP 4: 公開して動作確認する（待ち時間込み 5〜10分）

1. 右上「**作成**」を押す → 公開範囲は「**自分のみ**」を選ぶ（検品者であるマネージャー専用。部下への共有はしない）
2. 作成完了後、エージェントの共有設定（「…」→「共有」）を開き、共有範囲が「自分のみ」になっていること、共有リンクが誰にも発行されていないことを確認する
3. **5 分待つ**（ナレッジのインデックス作成に数分かかる。直後に試すと「見つからない」と答えるが故障ではない）
4. エージェントとのチャットで以下を 1 つずつ投げ、期待どおりか確認する（受け入れ基準は `tests.md` にも記載）:

| # | テスト質問 | 期待する挙動 |
|---|---|---|
| 1 | 攻め筋リストの接点列を最新化してほしい | タスク類型⑤・成果物定義・SOP5手順以上・目安時間付きのカード下書きが出る |
| 2 | 実測して資料も作って | 成果物が2つに分かれるため、カード2枚に分割提案される |
| 3 | ファイルパスや対象リストを言っていない依頼（例: ○○社のデータをまとめておいて） | SOP内の固有情報が【要記入】のまま残る（創作パスが書かれたらNG） |

## 更新のしかた（運用開始後）

- **タスク類型テンプレ.mdの手順を変えたいとき**: ローカル正本 `03_タスク工場\タスク類型テンプレ.md` を直し、`agents/docs/ナレッジ配置手順.md` の手順1〜3でSharePointの `ナレッジ/03_SOP` へ再配置する。エージェント側の操作は不要。反映まで数分
- **指示（instructions）を変えたいとき**: `agents/CPA-003-task-card-draft/instructions.md` を直し、`spec.md` の変更履歴に理由（Why）を記入したうえで、エージェントの「編集」画面の指示欄を全文貼り替える

## うまく動かないとき

| 症状 | 原因と対処 |
|---|---|
| 「情報が見つからない」と答える | インデックス未完了（数分待つ）／権限不足（STEP 1の確認表・権限を確認） |
| タスク類型テンプレ.mdの8類型と違う分類を返す | STEP 1の4番（`ナレッジ/03_SOP` への配置）が未完了、またはSharePointのインデックス反映待ち |
| 【要記入】を使わず固有情報を創作して埋める | 指示欄の「規則」セクションが貼り替え時に欠落していないか確認する（STEP 2の指示欄全文と一致しているか） |
| 部下や他の利用者が使えてしまう | STEP 4の2番の共有設定確認に戻り、共有範囲を「自分のみ」に修正する |
