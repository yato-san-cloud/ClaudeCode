# 用語集(営業管理) — エージェント共通ナレッジ

エージェントはこの語彙を**そのまま**使う。言い換え・新語の発明をしない。

## 活動区分(7種のみ。これ以外の語は使わない)

| 活動区分 | 使う場面 |
|---|---|
| 顧客訪問 | 先方への訪問・来所対応(対面) |
| 打合せ | オンライン含む商談・社内外の打合せ |
| メール | 提案・見積・資料の送付、重要なやり取り |
| 電話 | 架電・受電で案件が動いたもの |
| 定例会・分科会 | 定例化された会議体 |
| 現場調査 | 現地確認・実測・見学会 |
| その他 | 上記以外(展示会対応など) |

## 案件ステータス(CRM準拠、L区分)

1.0.案件登録 / 1.2.コンタクト成功(L1) / 2.1.案件規模確定(L2) / 2.2.見積依頼受領 /
3.1.提案書たたき台作成済(L3申請) / 3.2.提案済 / 3.3.フォローアップ / 4.1.受注(L4) /
4.2.立上準備中 / 4.3.立上後フォロー / 保留中 / 失注 / 中断
※ステージ略記: L1/L2/L3/L4/保留/失注/中断

## 商談フェーズ(顧客側の状態)

1.案件登録(ヒアリング中) / 2.課題の認識・特定 / 3.提案内容の評価 / 4.最終意思決定・稟議 /
5.立上げ準備 / 6.稼働開始 / 失注 / 中断

## 受注確度

Z(受注) / A / B / C / D(確度はZに近いほど高い) / Y(翌期以降) / 失注 / 中断

## 案件の区分語彙

- 受注区分: 新規受注 / 既存拡大 / 再受注 / 再編 / -(単発)
- 案件区分: 開発 / 保守 作業区分: 継続 / 単発
- 独自・共同: 独自 / 共同(中発) / 共同(本発) / 共同[MA2] / 共同[MA3]
- 旗艦タグ: 旗艦(証拠工場をフル発動する大型案件) / 標準
- 経路タグ: 既存深耕 / 佐川協創 / グループ伝手 / 協力会社 / レーダー / 展示会 / その他

## 拠点略号

[静東]=静岡東部(新富士DPL・新富士センター等) / [静西]=静岡西部(袋井・牧之原・掛川等) /
[清水] / [掛工]=掛川の顧客構内

## 数字・日付の書式

- 金額: 「1.2M¥/月」(百万円/月)。単発は「総額8.0M¥」
- 面積・人員: 「1,600坪/50名」
- 日付: 文中は「7/8」、フィールド値は「2026-07-08」

## 報告の語感(決裁者向けに書く時)

- 数字は可能ならレンジ+確度+確定タイミングで(「約900〜950万、8月のIT見積で確定」)
- 悪い情報は先回りで開示(ダウンサイドを聞かれる前に書く)
- 「合意」と書けるのは文書・メールの証跡がある時だけ。口頭は「口頭承諾」「合意的方向」と書き分ける
