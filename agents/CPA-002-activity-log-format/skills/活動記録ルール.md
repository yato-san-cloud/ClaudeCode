# 活動記録ルール — エージェント用ナレッジ

活動ログ(kintone)1レコードの書き方。活動記録整形エージェントはこの形式で出力する。

## フィールドと書式(1活動=8行)

```
実施日: 2026-07-08
取引先: 三生医薬
案件: T-003 調達資材の保管・工場横持ち
活動区分: 顧客訪問
タイトル: 保管エリア見積の承諾合意
活動内容: 内藤氏より見積承諾の承認メールを頂ける旨の合意。監査対応(おんどとり・防虫)の
見積は6/17訪問時に提示することで確認。
ネクストアクション: 6/17訪問時に監査対応見積を提示
NA期日: 2026-07-17
```

## 良い例・悪い例

**良い例(電話)**
```
実施日: 2026-07-08
取引先: 未紐付け(→○○製紙)
案件: 未紐付け
活動区分: 電話
タイトル: 初回アポイント打診
活動内容: 総務部経由で物流担当につないでもらう約束を取得。担当者名は次回架電で確認。
ネクストアクション: 再架電
NA期日: 2026-07-14
```

**悪い例(何がだめか)**
```
活動内容: 三生さんに行っていろいろ話した。いい感じだった。また行く。
```
→ 事実(何を提示/合意したか)、相手の反応(誰が何と言ったか)、次の行動(いつ何を)が全部ない。

## ルール

1. 1活動=1レコード。1日に2社訪問したら2レコードに分割
2. タイトルは15字以内の要点(RFP受領/概算見積提示/現地調査 実施 など)
3. 活動内容は「事実→相手の反応→自社の対応」の順で2〜4行
4. 聞き取れない・不明な値は【要確認】を付けて仮置き(勝手に確定しない)
5. 取引先名は案件リスト_最新.mdの正式表記に正規化。無い社名は「未紐付け(→社名)」
6. ネクストアクションは必ず埋める(本当に無いときだけ「なし」)
