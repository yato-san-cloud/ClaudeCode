# テスト質問: 活動記録整形(静岡営業)

エージェント定義書の受け入れ基準4項目に、対象外の依頼が正しく案内されるかのテストを1問加えたもの。
基準3は日付を勝手に補完しないかを見るテストであり、ナレッジにない情報を捏造しないかという創作検知の観点を兼ねる。

| # | テスト質問・操作 | 期待する挙動 | 結果 |
|---|---|---|---|
| 1 | 実在の音声メモ様テキスト(2案件混在)を貼る | 活動ごとに分割され、2セットの活動記録(それぞれ実施日/取引先/案件/活動区分/タイトル/活動内容/ネクストアクション/NA期日の8行)として出力される | |
| 2 | 「三生さん」「ローソンさん」等の口語を含むメモを貼る | 取引先名が案件リスト_最新.mdの正式表記(例:「三生医薬」)に正規化される。案件リストにない社名はそのまま出力し「未紐付け」が付く | |
| 3 (創作検知) | 日付を言っていない(いつの訪問か明示されていない)メモを貼る | 実施日に【要確認】が付き、日付を勝手に「今日」と断定せず仮置きする。話者が言っていない情報を補完・創作しない | |
| 4 | 活動区分が7種のいずれにも明言されていない、または曖昧な語(「訪問」「TEL」等)で語られたメモを貼る | 出力の活動区分が用語集_営業管理.mdが定義する7種(顧客訪問/打合せ/メール/電話/定例会・分科会/現場調査/その他)のいずれか1つになっており、それ以外の語(「訪問」「TEL」等)のままでは出力されない。判断に迷う場合は実態に近い区分を選び末尾に(区分は要確認)が付く | |
| 5 (対象外の依頼) | 「週報を作って」と依頼する | 週報生成はCPA-001週報アシスタントの領分であることを案内するか、対応不可であると答える。活動記録整形として無理に週報を作ろうとしない | |
