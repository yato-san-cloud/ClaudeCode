# 配備ガイド: 活動記録整形(静岡営業)

所要時間の目安: 25分(うち待ち時間 5〜10 分)

## STEP 1: ナレッジの配置を確認する(5分)

前提: `agents/docs/ナレッジ配置手順.md` の手順1〜3(サイトとライブラリ作成→OneDrive同期→台帳スナップショットの自動出力)が完了していること。未完了の場合は先にそちらを実施してからここに戻る。

1. ブラウザでSharePointサイト「営業管理」を開く
2. 「ドキュメント」ライブラリ内の `ナレッジ` フォルダを開き、以下の3ファイルが配置されているか確認する:

| # | ファイル名 | 配置先フォルダ | 種別 | 確認内容 |
|---|---|---|---|---|
| 1 | 活動記録ルール.md | ナレッジ/01_フォーマット | 静的(正本: このリポジトリの agents/CPA-002-activity-log-format/skills/) | 内容がリポジトリの最新版と一致しているか |
| 2 | 用語集_営業管理.md | ナレッジ/00_共通 | 共有(正本: agents/shared-knowledge/。CPA-001・CPA-003と共通参照) | 活動区分7種の表が最新か |
| 3 | 案件リスト_最新.md | ナレッジ/02_台帳スナップショット | 動的(gen_knowledge.py出力。版管理対象外) | ファイルの更新日時が直近(1週間以内目安)か。古い場合はgen_knowledge.pyを再実行する |

3. **権限確認**: ライブラリの「…」→「アクセス許可の管理」を開き、このエージェントを使う静岡営業課の全員(オーナーと共有先の部下)に閲覧権限があることを確認する

## STEP 2: エージェントを作成する(5分)

1. ブラウザで `https://m365.cloud.microsoft/chat` を開く(または Teams の Copilot)
2. 右側ペインの「エージェント」→「**エージェントを作成する**」をクリック
3. 「**構成**」タブに切り替える(「説明」タブの対話形式は使わない。構成タブに直接貼る方が確実)
4. 各欄に下の表の内容を**そのまま**貼り付ける:

| 画面の欄 | 貼り付ける内容 |
|---|---|
| 名前 | [CPA-002] 活動記録整形(静岡営業) |
| 説明 | 外回り後の音声メモや走り書きを、活動ログ(kintone)にそのまま貼れる形に整形します。モバイルからの利用を想定。 |
| 指示 | 下の「指示欄の全文」をすべてコピーして貼る |
| 会話のきっかけ(スターター) | ① これを活動記録にして:(文字起こしを貼る) ② 今日の三生医薬訪問、メモはこれ:(走り書き) ③ 電話メモ。○○社から折り返し、内容は… |

### 指示欄の全文(ここから下をコピー)

```
あなたは営業活動の記録係です。音声メモの文字起こしや走り書きを、kintone活動ログに貼り付けられる形に整形します。

# 出力フォーマット(活動記録ルール.mdに準拠。1活動につき次の8行)
実施日: YYYY-MM-DD
取引先: (案件リスト_最新.mdの正式表記に合わせる)
案件: (管理ID+案件名。案件リストで特定できない場合は「未紐付け(→社名)」)
活動区分: 顧客訪問/打合せ/メール/電話/定例会・分科会/現場調査/その他 のいずれか1つ
タイトル: (15字以内の要点。例: RFP受領、概算見積提示)
活動内容: (2〜4行。事実→相手の反応→自社の対応の順)
ネクストアクション: (1行。なければ「なし」)
NA期日: YYYY-MM-DD(不明なら「未定」)

# 規則
- 1つのメモに複数の訪問・案件が含まれていたら、活動ごとに分割して複数セット出力する。
- 話者が言っていないことを補完しない。日付・社名・数字が聞き取れない場合は【要確認】を付けて仮置きする。
- 取引先名は案件リストの表記に正規化する(例:「三生さん」→「三生医薬」)。リストにない社名はそのまま+「未紐付け」。
- 活動区分は必ず7種から選ぶ。判断に迷ったら「打合せ」でなく実態に近い方を選び、末尾に(区分は要確認)と添える。
- 敬称・感想・言い淀みは落とす。事実と決定事項とネクストアクションだけを残す。

# ふるまい
- まず整形結果を出す。質問はしない(【要確認】マークで人に判断を返す)。
- 出力の最後に「↑そのままkintone活動ログへ。【要確認】箇所だけ直してから確定してください」と1行添える。
```

## STEP 3: ナレッジを登録する(2分)

1. 同じ「構成」タブの「**ナレッジ**」セクションで「SharePoint」を選ぶ
2. 検索欄に「営業管理」または各ファイル名を入力し、STEP 1 で配置を確認した3ファイル(活動記録ルール.md、用語集_営業管理.md、案件リスト_最新.md)をすべて選択する
3. 「Web コンテンツ」等の他ソースは**オフのまま**にする(定義書の「機能: すべて不要(Web検索オフ)」のとおり、社内ナレッジ以外から回答させないため)

## STEP 4: 公開して動作確認する(待ち時間込み 5〜10分)

1. 右上「**作成**」を押す→公開範囲は「**自分のみ**」を選ぶ(部下への共有は STEP 5 で行う)
2. **5 分待つ**(ナレッジのインデックス作成に数分かかる。直後に試すと「見つからない」と答えるが故障ではない)
3. エージェントとのチャットで以下を 1 つずつ投げ、期待どおりか確認する:

| # | テスト質問・操作 | 期待する挙動 | 結果 |
|---|---|---|---|
| 1 | 実在の音声メモ様テキスト(2案件混在)を貼る | 2セットの活動記録に分割されて出力される | |
| 2 | 「三生さん」「ローソンさん」等の口語を含むメモを貼る | 取引先が案件リスト_最新.mdの正式表記に正規化される | |
| 3 | 日付を言っていないメモを貼る | 実施日に【要確認】が付き、日付を勝手に「今日」と断定しない | |
| 4 | 活動区分が曖昧なメモを貼る(「訪問した」「電話した」等) | 活動区分が用語集の7種(顧客訪問/打合せ/メール/電話/定例会・分科会/現場調査/その他)のいずれかで出力され、それ以外の語(「訪問」「TEL」等)にならない | |
| 5 | モバイル(Teams/Copilotアプリ)から同じメモを貼って試す | PC版と同じ整形結果が得られ、表示が崩れない | |

## STEP 5: 部下に共有する(5分)

このエージェントは静岡営業課の部下に共有して使わせる前提。作成者自身の動作確認(STEP 4)が完了してから行う。

1. 作成したエージェントの詳細画面右上の「**共有**」ボタンをクリックする
2. 「特定のユーザーとグループ」を選び、共有する部下のメールアドレスを入力して追加する(全社公開・組織全体への共有はしない)
3. 「共有」を確定する
4. 部下側の開き方: 部下はモバイルの Teams または Copilot アプリを開き、「エージェント」一覧(または Copilot アプリ下部の「エージェントを見つける」)から「[CPA-002] 活動記録整形(静岡営業)」を検索して開く。共有直後は一覧に反映されるまで数分かかることがある
5. 部下の画面でも会話スターターが表示され、チャットできることを確認する(Copilot版_全体設計_v0.md §3 T1c「共有可否」テストに相当)

## 更新のしかた(運用開始後)

- **手順を変えたいとき**: このリポジトリの `agents/CPA-002-activity-log-format/skills/活動記録ルール.md` を更新→SharePoint「営業管理」ナレッジ/01_フォーマットの同名ファイルへ上書き(OneDrive同期フォルダにコピーするだけで反映。`agents/docs/ナレッジ配置手順.md` §2)。エージェント側の操作は不要。反映まで数分
- **案件リストを最新化したいとき**: `gen_knowledge.py` を再実行してSharePoint同期フォルダへ出力し直す(`agents/docs/ナレッジ配置手順.md` §3)。この操作は版管理対象外(spec.mdの変更履歴には記録しない)
- **用語集を変えたいとき**: `agents/shared-knowledge/用語集_営業管理.md` を更新する。CPA-001・CPA-003と共通のため、他エージェントの挙動にも影響することに注意する

## うまく動かないとき

| 症状 | 原因と対処 |
|---|---|
| 「情報が見つからない」と答える | インデックス未完了(数分待つ)/権限不足(STEP 1 の権限確認を再確認) |
| 取引先名が正規化されない・古い社名のまま | 案件リスト_最新.mdの鮮度が古い可能性。gen_knowledge.pyを再実行し、SharePoint側のインデックス反映(数分〜数時間)を待つ |
| 活動区分が7種以外になる | 用語集_営業管理.mdがナレッジに登録されているか(STEP 3)を確認する。登録済みでも改善しない場合はSTEP 3を再実施する |
| 一般知識で勝手に答える | エージェントビルダーの仕様上、一般知識の完全遮断は不可。指示欄の「ふるまい」規則が消えていないか確認する |
| 部下の一覧にエージェントが表示されない | STEP 5 の共有が完了しているか確認する。反映まで数分かかることがある |
