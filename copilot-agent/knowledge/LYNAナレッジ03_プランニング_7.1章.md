# LYNA自動配車クラウド ユーザーガイド 構造化ノート（7章 プランニング 前半）

## 7 プランニング
- **目的**: プランニング機能全体の目次章。配車計画（7.1）、共通マスタ（7.2）、マスタの共通機能（7.3）の3部構成を示す。
- **要点**:
  - 7.1 配車計画: 配車計画一覧 / 実績管理 / データ取り込み / 固定ルート / 空の配車計画の作成 / 一括自動配車 / 帳票一括出力
  - 7.2 共通マスタ: 訪問先管理 / 車両管理 / ドライバー管理 / 商品管理 / 各種設定
  - 7.3 マスタの共通機能: データの削除、出力、取り込み、検索、ソート、詳細表示、訪問先の検索、前後データへの移動
  - 計画画面内の機能の説明は別章「計画画面」を参照。
- **用語**:
  - **共通マスタ**: 訪問先・車両・ドライバー・商品・各種設定など、計画をまたいで共有されるマスタデータの総称。

## 7.1.1 配車計画一覧
- **目的**: 取り込み済みの配車計画を一覧表示し、計画名変更・ロック強制解除・コピー・確定・削除などの管理操作を行う画面。
- **要点**:
  - 一覧に表示されるのは、ユーザーのユーザーグループに閲覧・編集権限が設定された計画カテゴリーの配車計画のみ。
  - 各計画を右クリックすると操作メニューが表示される。
  - 計画が1件もない場合はダイアログが表示され、「新しいデータ取り込み設定の作成」から取り込み設定を作る。
  - **計画の確認・編集**: 左クリックで計画画面へ遷移。「新しいタブで計画を確認・編集する」で別タブ表示も可（元タブでは排他制御により「編集中」表示）。
  - **計画名変更**: 右クリック→「計画名変更」→名前入力→「変更」。
  - **ロックの強制解除**: 右クリック→「ロックの強制解除」→確認OK→「編集状況」欄が空白になる。
  - **計画のコピー**: 右クリック→「コピー」→コピー先の計画名と日付を入力→「コピーする」。
  - **計画の確定**: 右クリック→「確定する」→「編集状況」が「未確定」から「確定」に。確定するとドライバーがルート参照可能になる。
  - **計画の削除**: 個別はチェックボックス→「削除」→削除対象選択→確認OK。ヘッダー行チェックで一括削除も可能。
- **つまずきポイント/注意**:
  - ロック強制解除すると、編集中ユーザーの未保存の編集内容は破棄される。
  - 既存計画と同じ計画名+日付でのコピーは不可。
  - 積み置き連動が有効な場合、積み日・降ろし日・積み置き指定注文がある計画はコピー不可。
  - 削除した配車計画は元に戻せない。ロック中の計画は削除不可。
- **用語**:
  - **排他制御（ロック）**: 他ユーザー編集中の計画を同時編集できなくする仕組み。「（ユーザー名）が編集中」と表示される。
  - **計画の確定**: ドライバーによるルート参照を可能にする状態への切り替え。

## 7.1.2 実績管理
- **目的**: 登録済みの運行実績データの一覧表示・削除・取り込み・出力を行う。
- **要点**:
  - 取り込み対象ファイル: xlsx, xls, xlsm, csv。
  - 取り込み方法は2種: 「計画を無視してファイルのまま取り込む」（整合性を確認せずファイル順に取り込み。計画がなければ作成）/「計画の配車結果に一致するルートのみ取り込む」。
  - ヘッダーフォーマットは2種: 「日時、ステータス」（開始・終了をステータスで表現）/「開始日時、終了日時、ステータス」（開始・終了をヘッダーで表現）。
  - ステータスフォーマット: 「ライナ形式」は「日時、ステータス」の場合のみ選択可。「標準形式」ではジオフェンス半径(m)を設定し、荷積・荷卸の発生地点・時刻から到着・出発・荷役継続時間を決定する。
  - 「日時、ステータス」形式の必須項目: 日時(yyyy/MM/dd hh:mm:ss)、車両コード。ライナ形式では所在地コードまたは緯度経度が必要、標準形式では緯度経度が必須。
  - 「開始日時、終了日時、ステータス」形式の必須項目: 開始/終了日時、車両コード、開始/終了の緯度経度、ステータス。
  - ステータス値（ライナ形式）: 1=到着済み, 2=荷役開始, 4=荷役終了, 8=出発済み, 32=スキップ。
  - ステータス値（標準形式）: 01=出庫, 02=帰庫, 03=荷積, 04=荷卸, 05=待機, 06=休憩。
  - ヘッダー設定・ステータス設定で、ファイル側の項目名/ステータス値をシステム側項目にマッチング（読み替え）可能。
  - 削除・出力の操作はマスタ共通機能「データの削除」「データ出力」を参照。
- **つまずきポイント/注意**:
  - ファイル内に計画名がない場合は画面で入力した計画名が採用される。
  - 日付が空の場合は日時（または開始・終了日時）の日付が使用される。
- **用語**:
  - **ジオフェンス半径**: 地点を中心とした仮想的な円の半径。実績地点がこの範囲内にあるかで到着・出発・荷役時間を判定する。
  - **ライナ形式/標準形式**: 実績ステータスのコード体系の2種類。

## 7.1.3 データ取り込み
- **目的**: 取り込み設定を使ってエクセル/CSVファイルから注文・顧客・デポなどのデータを配車計画に取り込む。
- **要点**:
  - 新規取り込み手順:
    1. プランニング→「データ取り込み」をクリック。
    2. 設定済みの取り込み設定から使用する設定を選択。
    3. 「ファイルを選択」でファイルを指定。
    4. 対象日付を選択（未選択=全注文データ、選択=その日付のデータのみ。複数選択可、選択すると赤い丸）。
    5. 「データ取り込み実行」をクリック。
  - 完了時に車両マスタ未登録なら「かんたん車両一括登録」への案内が表示される（「はい」で起動、車両管理からも起動可）。
  - かんたん車両一括登録の入力項目: 車型名称、最大積載量、台数、出発時刻、終了時刻、最大訪問件数、最大回転数。共通マスタにも登録するなら「コピーする」、計画内だけなら「コピーしない」。
  - 作成済み計画への取り込み: 手順3の前に対象計画をプルダウンで選択し、既存計画と同じ日付を選ぶ。実行後、登録済みデータの扱いを5択から選択:
    1. ないデータは追加し、登録済みの顧客・デポデータは無視する（共通マスタは上書きしない、注文は上書き）
    2. ないデータは追加し、登録済みのデータは上書き更新する
    3. 取り込み済みの注文データをすべて削除する（計画内の注文を全削除し取り込みデータのみに）
    4. 取り込み済みの注文、顧客データをすべて削除する
    5. 取り込み済みの注文、顧客・デポデータをすべて削除する
- **つまずきポイント/注意**:
  - ファイルサイズ20MB超は使用不可。
  - 「すべて削除する」系で削除されるのは計画内マスタのデータのみ。共通マスタ[訪問先管理]の顧客・デポは削除されない。
  - 配車済みの場合、注文全削除するとルートも削除される。
  - 「高度な設定」の訪問先が[取り込まない][新規作成時のみ取り込む]の場合、共通マスタへの追加・更新や計画内マスタへの共通マスタデータの追加・更新はされない。
- **用語**:
  - **計画内マスタ**: 各配車計画の内部に保持されるマスタデータ（共通マスタとは別管理）。
  - **かんたん車両一括登録**: 車型単位で複数台の車両をまとめて作成する機能。

## 7.1.4 固定ルート
- **目的**: 登録済みの固定ルートパターンを一覧で確認・名称変更する画面（登録・配車は計画画面の「固定ルート」機能で行う）。
- **要点**:
  - 固定ルートパターンを右クリックで操作メニュー: (1)固定ルートパターンの確認 (2)新しいタブで固定ルートパターンの確認 (3)パターン名変更。
  - 確認では固定ルート参照画面へ移動し、パターンはヘッダー以外が黄色枠で表示。右側タブにパターン名・元計画の日付・元計画名が表示。
  - パターン名変更: 「パターン名変更」→名前入力→「保存」→「OK」。
- **つまずきポイント/注意**:
  - 固定ルート参照画面は参照のみ。編集したい場合は再度「固定ルート登録」から行う。
- **用語**:
  - **固定ルートパターン**: 既存計画から登録した、繰り返し使う定型の配車ルート。

## 7.1.5 空の配車計画の作成
- **目的**: データ取り込みを使わず、計画名と日付を指定して空の配車計画を手動作成する。
- **要点**:
  1. プランニング→「空の配車計画の作成」をクリック。
  2. 計画名と日付を指定。
  3. どの共通マスタのデータ・表示設定を計画にコピーするか選択し「作成」。
  4. 「計画表示・編集」をクリックすると作成した空の計画が表示され、計画内マスタに個別にデータ登録できる。
- **用語**: 計画内マスタ（7.1.3参照）。

## 7.1.6 一括自動配車
- **目的**: 既存の配車計画に対して、指定期間分の自動配車をまとめて実行する。
- **要点**:
  1. プランニング→「一括自動配車」をクリック。
  2. 「名称」で取り込み済みの配車計画から対象を1つ選択。
  3. 「スケジュールを作成する期間」を日付で選択。
  4. 「配車実行」をクリックすると該当計画の自動配車が実行される。
- **つまずきポイント/注意**（警告）:
  - 注文の所在地情報（デポ、顧客、車両の出発地/終了地）が合計7,000ヶ所以上ある場合、自動配車・一括自動配車は不可。
  - 注文データ自体が7,000件超の場合も不可。
- **用語**:
  - **自動配車**: 注文・車両条件からシステムが配車ルートを自動生成する機能。

## 7.1.7 帳票一括出力
- **目的**: 指定した期間の帳票をまとめて出力する。
- **要点**:
  1. プランニング→「帳票一括出力」をクリック。
  2. 「配車計画名」（出力したい計画）、「帳票名」（出力したい帳票）、「帳票を作成する期間」を指定。
  3. 「出力」をクリックすると帳票が出力される。
- **用語**:
  - **帳票**: 配車計画から生成する業務用出力ドキュメント（配車表など）。
