## 3. 基本的な使い方

- **目的**: 導入時の初期設定から日々の配車業務までの標準的な操作フローを3段階で示すページ。
- **要点**:
  - 【3.1 最初に設定すること(初期設定・この順序で)】
    1. 計画カテゴリーを作成(ユーザーグループに設定するため)
    2. ユーザーグループを作成(作成時に、1で作った計画カテゴリーの閲覧権限チェックボックスが表示される)
    3. ユーザーを作成(作成時に、2で作ったユーザーグループへの所属チェックボックスが表示される)
  - 【3.2 事前に設定すること】
    1. マスタデータ(訪問先、車型、車両など)を登録
    2. 配車をかけたい注文データを準備
    3. 新しいデータ取り込み設定の作成を行う
    4. 帳票出力する場合は帳票管理を設定
  - 【3.3 日々の基本的な使い方】
    1. 作成済みのデータ取り込み設定をもとに注文データの「データ取り込み」を実行
    2. 自動配車を実行(複数計画を一括→「一括自動配車」、1計画を個別→「自動配車」)
    3. 計画画面で配車結果を確認(修正したい場合は配車計画の「編集」)
    4. 帳票出力(必要な場合)
  - **つまずきポイント/注意**: 初期設定は「計画カテゴリー→ユーザーグループ→ユーザー」の順序が重要(後の作成画面で前のものを選ぶ構造のため)。データ取り込み設定を先に作らないと日々の取り込みができない。
- **用語**:
  - **計画カテゴリー**: 配車計画の分類単位。ユーザーグループの閲覧権限の対象。
  - **ユーザーグループ**: ユーザーの所属グループ。計画カテゴリーごとの権限を持つ。
  - **一括自動配車**: 複数の配車計画をまとめて自動配車する機能。
  - **データ取り込み**: 注文データ等をシステムに取り込む操作。

## 4. システムの全体像

- **目的**: システムの権限構成(ユーザー/グループ/計画カテゴリー)、自動配車に必要なデータ、データ取り込みの概念、マスタの2階層(共通/計画内)、複数拠点運用の設計方法を説明するアーキテクチャ解説ページ。
- **要点**:
  - 【4.1 構成(権限モデル)】
    1. ユーザーはユーザーグループに所属する
    2. ユーザーグループごとに、計画カテゴリーに対して閲覧権限を設定する
    3. 計画カテゴリー内に配車計画が存在し、ユーザーグループは権限のある計画カテゴリー内の配車計画を閲覧できる
    - 階層: ユーザー ∈ ユーザーグループ →(権限)→ 計画カテゴリー ⊃ 配車計画
  - 【4.2 自動配車に必要な情報】必須データと必須ではないデータに分かれる。※具体的な項目一覧は図(画像)で示されており本文テキストには含まれない(本文取得では画像内容不可)。
  - 【4.3 「データを取り込む」とは】「新しいデータ取り込み設定の作成」で取り込み項目を設定し、その設定をもとに配車計画に必要なデータへ「データ取り込み」を行う、という2段階の流れ。
  - 【4.4 共通マスタと計画内マスタ】
    - マスタは「共通マスタ」(メインメニュー配下)と「計画内マスタ」(各配車計画の中)の2種類。
    - 日々の配車計画作成時に、共通マスタをコピーして計画内マスタが作られる。
    - 共通マスタを変更しても、過去に作成済みの配車計画の計画内マスタには反映されない(重要注意)。
  - 【4.5 複数拠点での運用(業務フロー例)】
    - 計画カテゴリー×ユーザーグループの組み合わせで、拠点間の計画シェアや閲覧禁止など細かな役割分担が可能。
    - 例: 配送計画が「通常搬送品」(関東物流部担当)と「冷蔵搬送品」(関西冷蔵搬送部担当)の2種類。互いの計画は閲覧不可、「本部」は両方を閲覧・修正可。
    - 設定手順: (1)計画カテゴリーを「通常搬送品」「冷蔵搬送品」の2つ作成 → (2)ユーザーグループを作成し、関東物流部=通常搬送品のみ、関西冷蔵搬送部=冷蔵搬送品のみ、本部=双方の権限を付与 → 完了。
    - 複数拠点を想定しない場合は、計画カテゴリー・ユーザーグループを1つずつ登録するシンプル運用も可。
- **つまずきポイント/注意**:
  - 共通マスタの変更は既存計画の計画内マスタへ遡及反映されない(FAQ 15.1.2「共通マスタを更新したのに計画に反映されない」の原因)。
  - 4.2の必須データ一覧は画像のためテキスト抽出では内容未取得。原典ページの図を参照のこと。
- **用語**:
  - **共通マスタ**: メインメニューにある全計画共通のマスタ。
  - **計画内マスタ**: 各配車計画が持つマスタ。計画作成時に共通マスタからコピーされる。
  - **配車計画**: 計画カテゴリー内に作られる個々の配車プラン。

## 5. 初めてのログイン

- **目的**: ログイン直後に行うアカウント設定の変更方法と、メニューバー・リストメニューの画面構成を説明するページ。
- **要点**:
  - 【5.1 アカウントの変更】自身のメールアドレス(ログインID)、名前、パスワードを変更できる。
    1. メニューバーの「アカウント」をクリック
    2. 個人設定画面が表示される
    3. 任意の項目を変更し「設定」をクリック
  - 【5.2 メニューバーのその他のボタン】
    1. ユーザーガイド: 現在表示中の画面に対応するガイドページを開く
    2. 計画表示設定: 配車計画画面を見やすくする表示内容の設定(→8.8 計画表示設定)
    3. サポート: サポートセンターへの問い合わせ送信ページを開く(→16.3 お問い合わせのみ送信)
    4. ログアウト: ログアウトする
  - 【5.3 リストメニュー】「システム設定」クリックで「システム設定」リストメニュー、「プランニング」クリックで「プランニング」リストメニューが開く。
- **つまずきポイント/注意**:
  - テナントIDはお客様環境を一意に識別する数字で、サポート問い合わせ時に必要になることがある(個人設定画面で確認)。
  - ユーザーグループや権限の変更は本人ではできず、管理者権限のユーザーが「ユーザー」画面(6.3)から行う必要がある。
- **用語**:
  - **テナントID**: 顧客環境を一意に識別する数字。サポート問い合わせで使用。
  - **リストメニュー**: 「システム設定」「プランニング」をクリックすると開くメニュー群。
