# 引き継ぎブリーフ: 不具合連絡票 × データ品質検知の突合統合

宛先: 品質管理（データ検出）を進めている別セッション
目的: 現場申告（不具合連絡票）と機械検知（データ異常）を kintone 上で突合し、
**「データは異常なのに連絡票がない」＝起票漏れ**を鮮明にする。
このブリーフは自己完結。そのまま貼れば統合設計に入れる。

## 1. 何が強力か（設計意図）

独立した2チャネルの突合で、片側だけでは見えないものが見える:

| 突合結果 | 意味 | 使い道 |
|---|---|---|
| 両側一致 | 申告もデータも捉えた | 正常な運用 |
| **データのみ（連絡票なし）** | **起票漏れ／隠れ不具合** | 現場フィードバック・教育 |
| 連絡票のみ（データ異常なし） | データに現れないミス種 | 検知ロジックの盲点リスト＝品質管理側の改善ネタ |

## 2. こちら側で実装済みの資産（リポジトリ yato-san-cloud/ClaudeCode）

- **kintone「不具合連絡票」アプリ定義**: `tools/kintone_defects/create_app.py`（未デプロイ。フィールド22＋α個）
  - 発行方式: 票No＝レコード番号（発行済み→転記済み→確認済みの状態管理で転記漏れも検知）
  - **突合用に実装済みのフィールド**: `起票元`（現場連絡票/データ検知）、`突合結果`（未突合/両側一致/連絡票のみ/データのみ）、`発生工程`、`発見工程`、`事象タイプ`、`伝票番号`、`JAN`、`発生日`
- **転記パイプライン**: 写真→CPA-004（Copilotエージェント）→ `defects_upload.py`（JANチェックデジット・enum検証・漏れレポート。実物2票でdry-run検証済み）
- **分類の正典**: `docs/不具合分類_MECE化案.md`
  - 発生工程 enum: 入荷検収/格納/保管・棚移動/ピック/流通加工/検品/T-sort入荷/T-sort出荷/不明
  - 事象タイプ enum: 数量過剰/数量不足/品目相違/作業漏れ/位置相違/表示・ラベル不良/破損/システム・データ不整合/その他
  - 現行の紙12種→新軸の変換表は `defects_upload.py` の `EVENT_MAP` が実装

## 3. データ検知側への統合契約（あちらで実装するもの)

検知した異常を**同じ kintone アプリに 1 異常=1 レコードで起票**する。必須フィールド:

| フィールド | 値 |
|---|---|
| 起票元 | `データ検知`（固定） |
| 発生日 | 異常が発生した業務日 |
| 発生工程 | 上記 enum から（検知ロジック→工程の対応表をあちらで定義） |
| 事象タイプ | 上記 enum から（同上） |
| 伝票番号 / JAN | 特定できる方（両方あれば両方。突合キーになる） |
| 詳細 | 検知ロジック名＋根拠値（例: 「在庫差異検知: 理論在庫120 実棚118」） |
| 状態 | `転記済み`（発行フローを通らないため） |

重複起票防止: 検知ロジック名×キー×発生日で既存レコードを検索してから POST すること。

## 4. 突合ロジック仕様（どちらのセッションで実装してもよい）

週次実行。`起票元=現場連絡票` と `起票元=データ検知` のレコードを突き合わせ、
`突合結果` フィールドに書き込む。

- キー優先順位: ① 伝票番号 完全一致 → ② JAN×発生日(±1日) → ③ 発生工程×事象タイプ×発生日（弱一致・要目視）
- 一致 → 両レコードを「両側一致」に。相互のレコード番号を詳細末尾に追記
- データ検知のみ残 → 「データのみ(連絡票なし)」 ＝ **起票漏れ一覧として週次出力（最重要成果物）**
- 連絡票のみ残 → 「連絡票のみ(データ異常なし)」 ＝ 検知盲点一覧
- kintone API はレコード取得 `GET /k/v1/records.json`・更新 `PUT /k/v1/records.json`。
  認証は API トークン（`defects_upload.py` の `api()` 関数がそのまま流用可）

## 5. あちらのセッションで決めること

1. 検知ロジック一覧 → 発生工程・事象タイプへの対応表（enum は §2 のものに揃える。増やしたい値が出たらこちらの `create_app.py` と MECE 化案を先に改訂する——enum の二重管理をしない）
2. 検知の実行頻度と、kintone への起票タイミング（日次バッチ推奨）
3. 突合スクリプトをどちらの資産として持つか（検知側と同居が自然と考える）
