# 路線便タリフ計算ツール 市販調査レポート

調査日: 2026-08-14
目的: 路線便（特別積合せ）のタリフ運賃計算を楽にする市販ツールの有無・特徴を調べ、build vs buy 判断の材料にする。

---

## TL;DR

- **「契約タリフを入れたら路線便運賃が出る」安価な汎用SaaSは見当たらない。** 市場は下記5カテゴリに分かれる。
- 無料系（全ト協シミュレータ、各社Web見積り）は「標準的な運賃（≒貸切向け公示運賃）」ベースか1社ずつの都度入力で、**自社契約タリフでの計算には使えない**。
- 荷主向けの本命は **ノリック「運賃マスターズ」／日本アドレスタイプ「運賃計算システム」／ロジスティード「運賃計算システム」** あたり。ただしいずれも価格要問合せの導入型で、**契約タリフの登録は自前**。
- タリフ表・距離程表を「データとして買える」のは、はるかシステム研究所などのExcel系ニッチベンダーくらい。
- 計算自体は表引きの算数（Excel領域）。**めんどさの本質は計算ロジックではなく、各社バラバラなタリフのデータ化と改定追随**。
- 結論の方向性: 少数社・見積確認用途なら自作（Excel/小ツール）が最速。多社×大量出荷×請求照合まで要るなら市販導入を検討。

---

## 1. 前提整理：路線便タリフの構造と「めんどさ」の正体

路線便運賃の基本形は次の表引き計算。

```
運賃 = タリフ表[ 地帯区分(発地→着地), 重量帯(課金重量) ] × (1 − 割引率)
       + 各種割増（時間指定・特大品・離島/遠隔地など）
       + 燃料サーチャージ
課金重量 = max(実重量, 容積換算重量)   ※換算係数は会社・契約で異なる（例: 1m³≒280kg、1才≒8kg 等）
```

めんどさの正体は計算式ではなく、以下のマスタ整備・維持にある。

1. **各社タリフが独自仕様かつ実質非公開**（地帯区分の切り方も重量帯も社ごとに違う）
2. **「基準タリフの◯掛け」という相対契約文化**（同じ会社でも荷主ごとに割引率が違う）
3. **割増・サーチャージの多様さと改定頻度**（2024年問題以降、値上げ・サーチャージ改定が頻繁）
4. **複数社比較（最安選定）をすると計算件数が爆発**
5. **請求書との照合**（計算できないとチェックもできない）

体感の内訳: 計算ロジック2割、マスタ整備・維持8割。

## 2. 市販ツールマップ（5カテゴリ）

### A. 無料・公的系（「標準的な運賃」ベース）

| ツール | 提供元 | 概要 | 料金 |
|---|---|---|---|
| 標準的な運賃計算シミュレータ（Web版/アプリ版） | 全日本トラック協会 × 日貨協連 | 地域・車種・距離・時間を入れると令和6年告示「標準的な運賃」を計算 | 無料 |
| 標準的運賃 地図からの運賃計算システム（2025年7月公開） | 全日本トラック協会 | 地図上で発着地を指定して距離制運賃を算出。詳細版は住所入力・燃料サーチャージ・割増料金にも対応 | 無料 |
| トラクルGO 料金シミュレーター | トラクル | マッチングサイト付帯の標準的運賃簡易計算 | 無料 |

**注意**: 「標準的な運賃」は主に貸切（一般貨物）を想定した公示運賃で、**路線便（特積み）の各社実勢タリフとは別物**。価格交渉の参考指標・傭車運賃の目安としては有用。

### B. 路線会社公式の見積り・運賃表

| 会社 | 提供物 |
|---|---|
| 西濃運輸 | カンガルー便 運賃お見積り（Webフォーム） |
| 第一貨物 | 運賃お見積り（Webフォーム） |
| 日本通運 | 積合せ運賃・料金表（PDF公開。2026年4月改訂版あり） |
| 福山通運 | 各種料金表（フクツー宅配便等）・引越シミュレーション |

無料だが**1社ずつ・都度入力**で、公開されているのは基準運賃（定価）。契約割引は反映されず、横断比較や一括計算はできない。公開APIも見当たらない。

### C. 横断比較サイト（小口・宅配寄り）

| サービス | 概要 |
|---|---|
| 送料の虎（shipping.jp） | 宅配便・大型便の横断料金比較の定番。B2B路線便の契約タリフ比較には非対応 |
| 比較ビズ等の一括見積もりサイト | 複数運送会社への人力相見積もりマッチング。計算ツールではない |

### D. 荷主・3PL向け 運賃計算／最安選定／請求照合システム【本命ゾーン】

| 製品 | 提供元 | 特徴 | 料金 |
|---|---|---|---|
| 運賃マスターズ（トラック運賃計算システム） | ノリック | 登録した複数運送会社の情報から**最安運送会社を瞬時に割り出し**。出荷実績から地区・個数・重量別の最安分析、請求チェック自動化。導入事例で運賃コスト約7%減 | 要問合せ（イージーオーダー型） |
| 運賃計算システム | 日本アドレスタイプ | **路線便の複雑な条件のタリフ運賃を高精度計算**（個建・重量運賃・特別条件対応）。運賃を日次把握、請求チェック自動化、部門別・製品別の運賃配賦 | 要問合せ |
| 運賃計算システム | ロジスティードソリューションズ | 区域・**路線タリフ**・コンテナ便運賃から基準運賃を算出。冬季/休日割増など課金パターン豊富。請求運賃・支払運賃の両対応。TMS製品群の一部 | 要問合せ |
| ULTRAFIX/運輸管理 | NECソリューションイノベータ | デジタル地図の走行距離・車種・重量からタリフで計画運賃を算出。TMS（配車計画等）と一体 | 要問合せ |

**共通の特徴**: どれも「自社の契約タリフをマスタ登録」して使う前提で、**タリフデータは付属しない**。初期費用＋カスタマイズの導入型で、小規模用途にはオーバースペックになりがち。

### E. 運送事業者向け 基幹システム/TMS（請求側の運賃計算）

| 製品 | 提供元 | 特徴 |
|---|---|---|
| 轟〜TODOROKI〜 | 東計電算 | クラウド運送業基幹。受注〜配車〜請求・支払を一括管理 |
| トラックメイトPro | タイガー | 得意先（荷主）別の運賃テーブルで単価自動算出。日報入力から請求・経費・給与データまで作成 |
| ロジックス（LogiX） | アセンド | 受注〜配車〜請求のクラウドTMS。10〜500台規模の一般貨物事業者向け。原価・利益率の自動可視化 |
| AIR | 五十鈴 | ドライバーアプリの動態データ（走行距離・待機時間）から適正運賃請求 |

自社が**運送事業者で「請求する側」**の場合はこのカテゴリ。荷主の支払運賃計算が主目的ならDが該当。

### F. Excel・データ販売系（ニッチだが実務直結）

| 提供元 | 内容 |
|---|---|
| はるかシステム研究所 | 令和6年標準的な運賃・**過去年度の貸切/特別積合せ運賃表**・全市区町村距離程表・電子キロ程図・Excel距離運賃計算。**タリフ・距離データそのものを購入できる希少な存在**（有償） |
| アドバンスド・コア・テクノロジー（ACT） | 「運賃計算ワークシート for Excel」。ACT距離計算サービスと連動してExcel上で運賃計算 |
| TYKシステムズ | 住所リスト×キロ程×運賃タリフ表からの一括運賃計算ツール |
| エスワイ・リンク | 距離・運賃計算ツール |
| （DIY） | PowerQueryでタリフ表マトリクスを正規化する手法記事、Excelマクロでの運賃自動計算記事など多数。Excelで自作するのは業界的に一般的 |

## 3. 問題タイプ判定：これは「Excel領域（算数）」

warehouse-planner の判定フローに当てはめると:

- **Q1. 閉形式で書けるか？ → Yes。** 上記の表引き＋係数の式で書ける。
- 確率性なし、最適化要素なし（最安選定もN社を計算してminを取るだけ）。
- → **シミュレーションも数理最適化も不要**。XLOOKUP 2段＋割増ルールのレベル。

つまり「ツールがない＝技術的に難しい」のではなく、**各社タリフという非公開マスタを誰も共通データ化できていない**ことが市販ツールが薄い理由。逆に言えば、自社の契約タリフさえCSV化すれば自作ツールは小さく作れる。

## 4. Build vs Buy の目安

| 用途 | 推奨 |
|---|---|
| たまの見積り確認（〜数社） | 各社Web見積り＋Excelで十分（無料） |
| 出荷都度の運賃把握・最安社選定 | **自作が最速**（契約タリフのCSV化＋計算エンジン＋比較表示）。市販なら運賃マスターズ／日本アドレスタイプ |
| 請求照合・物流費の部門/製品配賦まで | 市販導入を検討（日本アドレスタイプ／ロジスティード／ULTRAFIX、またはTMS一式） |
| 自社が運送事業者（請求側） | 基幹系（轟／トラックメイトPro／ロジックス／AIR） |

- **自作が有利な理由**: ①契約タリフはどのみち自分で登録する ②計算は算数 ③市販は要問合せ価格・導入型で小規模だと重い。
- **市販が有利になる境目**: 運送会社数×出荷件数が多く、請求照合・原価配賦・基幹システム連携まで踏み込むとき。

---

## 5. 次の一手（提案）

1. **契約タリフの棚卸し** — 何社分あるか、紙/PDF/Excelどの形式か、割引率・割増条件・容積換算の取り決めを整理
2. **共通スキーマ設計** — 発地帯×着地帯×重量帯のロングフォーマットCSV＋割増ルール定義（ここが資産になる）
3. **1社分でPoC** — Excel（XLOOKUP）または小さなWebツールで計算検証 → 複数社比較・最安表示へ拡張

このリポジトリで「タリフCSV＋計算エンジン＋比較UI」のPoCツールはすぐ作れる規模感（シミュレーション不要の純粋な表引き）。
