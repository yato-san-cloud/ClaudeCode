# 運用ルール: 命名・版管理・正本(v1)

- 作成: 2026-07-02
- 目的: 頭の中にあった暗黙ルールを明文化し、AIセッション・他メンバー・将来の自分が同じルールで動けるようにする
- 適用範囲: プロジェクトフォルダ(Drive)配下の全成果物。既存ファイルの遡及リネームは**しない**(リンク切れ防止)

## 1. ファイル命名規則

### 基本形
```
[案件タグ]_内容_対象_vN[_YYMMDD].拡張子
例: 0629_WMS改修方針_IT部門打合せ_議事録_v1.docx
例: 審議回答_数字1枚_260702.html
例: (ローソン)2拠点化費用まとめ_260520_Rev10.xlsx
```

### 規則
| # | ルール | 理由 |
|---|---|---|
| N-1 | 日付は `YYMMDD` 6桁(例: 260702)。会議起点の文書のみ会議日を `MMDD_` 接頭辞にしてよい | 既存慣行に一致。ソートが効く |
| N-2 | 版は文書系=`v1, v2, v3, v3_1`、収支系=`Rev9, Rev10`、シナリオ系=`P1, P2, P3` を使い分ける | 既存慣行の追認。混用しない |
| N-3 | ファイル名に「最新」「final」「fix」「確定版」を**入れない** | 次の版が来た瞬間に嘘になる。最新の宣言はMOCの★で行う |
| N-4 | 区切りはアンダースコア。半角スペースは使わない | リンク・スクリプト処理の安定性 |
| N-5 | 配布物には宛先がわかるタグを付ける(`ローソン様向け_` `篁さん用_` `社内説明_`) | 誤送付防止の第一防壁 |
| N-6 | 仮版は名前でなく**文書冒頭に「⚠️仮版」**と書く(名前は普通にvNで進める) | 名前の「仮」は外し忘れる。中身の警告は目に入る |
| N-7 | セッション間文書は `依頼_内容_to_宛先_from_発信元_YYMMDD` / `回答_` / `通知_` | 既存プロトコルの追認 |

## 2. 版管理ルール

| # | ルール |
|---|---|
| V-1 | 新版を作ったら、旧版の扱いを**その場で**決めてMOCに注記する: `（参考、最新はvX）` を旧版の行に付ける |
| V-2 | ★は「現役の正本」にのみ付ける。同一系統に★が2つ以上あってはならない(moc-audit Skillが検査) |
| V-3 | 版を上げる=内容の意思決定があったとき。誤字修正程度は同版を上書き |
| V-4 | 3版以上前のものはアーカイブフォルダ(`99_アーカイブ/`)へ移動候補。移動は棚卸し時に人間が実行 |
| V-5 | 収支Revを上げたら `templates/Rev更新チェックリスト.md` を必ず一巡する |

## 3. 正本(正となるファイル)ルール

既存運用「mdで生成→人間が手動微修正→docxが正本」を公式化する。

| # | ルール |
|---|---|
| M-1 | 文書のライフサイクル: **md(AI生成ドラフト) → 人間修正 → docx/xlsx(正本) → 配布** |
| M-2 | docxに手動修正を入れた時点で、そのmdの冒頭に `> ⚠️ 正本は同名.docx(手動修正済)。再生成時は差分に注意` を追記する |
| M-3 | mdを再生成する場合は、先にdocxとの差分を確認してから(0514議事録の教訓) |
| M-4 | 正本の場所は1箇所。コピーを別フォルダに置かない(必要ならMOCリンクで参照) |
| M-5 | 数字の正本は常にxlsx(またはnumbers.json)。md/html/pptx側の数字は「転記」であり、食い違ったらxlsxが勝つ |

## 4. 機密区分ルール

| 区分 | 例 | 扱い |
|---|---|---|
| 🔒私的メモ | 交渉戦略メモ、人物評 | 配布禁止。ファイル冒頭に「私的メモ・配布禁止」明記。AIに議事録・配布物を作らせる際、**入力に混ぜない** |
| 社内限り | 想定問答、見積対比、削減交渉資料 | 宛先タグ`社内説明_`。顧客向け文書の生成時に参照可だが転記不可 |
| 配布可 | 議事録(正本)、IF確認書、調査シート | 配布前チェックリストを通してから送付 |

## 5. AIセッションへの適用

- 各Skillはこのルールを前提とする(Skill側にも要点を再掲済み)
- AIが新規ファイル名を提案する際は本規則に従う。違反を見つけたら黙って直さず**指摘だけ**する(遡及リネーム禁止のため)
- 定期検査: `scripts/name_lint.py` にファイル名一覧を渡すと違反を列挙する(読取専用・何も変更しない)
