# カイロ骨盤分析アプリ — インストールと使い方

X線（レントゲン）骨盤画像に基準点と分析線を引き、傾き・高低差・偏位を計測するアプリです。
Google Form問診票からの紹介状PDF作成機能も同梱しています。

**インストール不要の単体アプリ**として、Mac用・Windows用をそれぞれ配布します。

---

## 1. どのファイルを使えばいい？

| お使いのPC | ファイル |
|---|---|
| **Mac（Apple Silicon: M1/M2/M3/M4）** | `ChiroApp-macOS-AppleSilicon.zip` |
| **Mac（Intel）** | `ChiroApp-macOS-Intel.zip` |
| **Windows 10 / 11** | `ChiroApp-Windows-x64.zip` |

**Macのチップの確認方法**: 画面左上のリンゴマーク →「このMacについて」。
「チップ Apple M1」等とあれば Apple Silicon、「プロセッサ Intel Core i5」等とあれば Intel です。

---

## 2. Macでのはじめ方

1. zipをダブルクリックして展開 → `ChiroApp.app` が出てきます
2. `ChiroApp.app` を「アプリケーション」フォルダへドラッグ（推奨）
3. **初回のみ**: そのままダブルクリックすると「開発元を検証できないため開けません」と表示されます
   - **方法A**: アプリを右クリック（Control+クリック）→「開く」→ダイアログで「開く」
   - **方法B**（macOS Sonoma/Sequoia以降で方法Aが出ない場合）:
     システム設定 → プライバシーとセキュリティ → 下部の「"ChiroApp"は開発元を確認できないため…」の横の**「このまま開く」**
4. 2回目以降は普通にダブルクリックで起動します

> これはApple未登録の個人配布アプリに必ず出る標準の警告です。アプリ自体の異常ではありません。

## 3. Windowsでのはじめ方

1. zipを右クリック →「すべて展開」→ `ChiroApp.exe` が出てきます
2. `ChiroApp.exe` をダブルクリック
3. **初回のみ**「WindowsによってPCが保護されました」と出る場合:
   **「詳細情報」→「実行」** をクリック
4. 初回起動は展開処理のため十数秒かかることがあります（2回目以降は速くなります）

> 万一ウィンドウが開かず既定のブラウザが立ち上がった場合も、そのまま同じ機能が使えます。

## 4. X線分析の使い方（基本の流れ）

![分析画面](images/xray_02_detected.png)

1. **画像の読み込み** — X線画像（JPG/PNG）をドラッグ&ドロップ
2. **分析タイプ** — 通常は「骨盤総合（Gonstead式）」のまま「基準点を自動検出」
3. **基準点の補正** — 自動検出は初期値です。必ず目視で確認し、ズレていれば補正してください
   - 点を**ドラッグ**で移動 / クリックで選択して**矢印キー**で1px微調整（Shift+矢印で5px）
   - **ホイールでズーム**、背景ドラッグで表示位置の移動
   - 「元に戻す」(Ctrl+Z) でひとつ前へ
4. **画像調整** — コントラスト/明るさ/ネガ反転で骨縁を見やすく（計測には影響しません）
5. **スケール設定** — 画像に定規やキャリブレーションボールが写っている場合、
   その両端に紫の2点を合わせて実寸(mm)を入力すると、**全計測値がmm表示**になります。
   未設定の場合は誇張を避けるため px 表示のままです
6. **出力** — 「分析レポートPDF」「注釈入りPNG」「紹介状に添付」「セッション保存(.json)」

### 計測している項目（骨盤総合）

- **大腿骨頭ライン(FHL)の傾斜** — 左右の大腿骨頭を結ぶ基準線の角度
- **大腿骨頭 高低差** — 脚長差の指標
- **腸骨稜高（左右・FHL基準の垂直距離）と高低差** — 骨盤の傾き
- **恥骨結合・S2の側方偏位** — FHL中点の垂直軸からの水平ずれ

### 左右の表記について

正面(AP)像の標準表示（**画面の左＝患者の右**）を前提に「右/左」を表示します。
画像がPA像・左右反転の場合は「表示設定 → AP標準」のチェックを外してください。
画面上のR/Lマーカーも連動します。

---

## 5. 注意事項

- 計測値は画像上の基準点に基づく**参考値**です。X線画像の診断は医師が行うものであり、
  本アプリは施術方針検討の**補助ツール**です
- 撮影時の拡大率・ポジショニングにより実寸との誤差が生じます。mm値が必要な場合は
  必ずスケール設定（キャリブレーション）を行ってください
- 患者データはPCの外に送信されません（すべてローカル処理）

## 6. 配布ファイルの入手（開発者向けメモ）

GitHubリポジトリの **Actions → Build desktop apps** の最新実行から
3種のzip（Windows / macOS Intel / macOS Apple Silicon）をダウンロードできます。
コードを更新してブランチにpushすると自動で再ビルドされます。

署名について: 現在は未署名ビルドのため、上記の初回起動手順（Gatekeeper / SmartScreen）が
必要です。恒久的に警告を消すには Apple Developer Program / コード署名証明書での
署名・公証が別途必要になります。
