# whsim ユーザーガイド（営業向け）

このガイドは、倉庫の専門知識がなくても whsim で顧客提案を作れるように書いています。
専門用語は最小限です。困ったら画面右下の **Cody（コディ）** に日本語で話しかけてください。

---

## 1. whsim とは

**「ゆるく組めて、裏で本格シミュレーションが走る」倉庫シミュレータ**です。

- あなた（営業）は、テンプレートから倉庫を**ざっくり**組むだけ。
- 裏側では離散事象シミュレーション（DES）が動き、作業員・AGV の動きを再現します。
- 結果は **提案書にそのまま貼れる1枚の絵（PNG）** と **PPTX/PDF の提案書**になります。

「全部の数字を埋めないと動かない」既存ツールと違い、**埋まっていない項目は仮値**で
動き続けます。顧客の実データ（分析ツールの ZIP）が来たら、その部分だけ上書きされ、
出力には「**N% your data（あなたのデータが何%か）**」が明記されます。

---

## 2. 起動する

```bash
pip install -e ".[dev,web]"
whsim serve
```

ブラウザで **http://127.0.0.1:8000** を開きます。

> Windows なら、リポジトリ直下の **`start.bat` をダブルクリック**するだけでOK
> （初回は依存を自動インストール→ブラウザが開きます。停止は Ctrl+C）。

---

## 3. Cody に話しかけて進める（チャット先行）

画面のマスコット **Cody** に日本語で頼むだけで、主要操作ができます。

| こう言うと | Cody がやること |
|---|---|
| 「EC倉庫を作って」「『テスト倉庫』を作って」 | テンプレからプロジェクト作成 |
| 「シミュレーションを回して」 | 実行（2Dアニメ・KPI が出る） |
| 「結果を見せて」「KPIは？」 | 分析ダッシュボードを開く |
| 「繁忙期と比べて」「AGV入れたらどうなる？」 | シナリオ比較を開く |
| 「ざっくり概算して」 | 待ち行列式の即時見積り |
| 「使い方を教えて」 | できることの一覧 |

Cody が分からなければ、やさしく候補（チップ）を出します。名前が必要なときは
「名前は何にする？」と聞いてくれます。

---

## 4. 基本の流れ：作る → 実行 → 分析 → 提案書

1. **作る**：テンプレ（例：`ecommerce_small`）を選ぶ。この時点で必ず動きます。
2. **（任意）取り込む**：顧客の分析ツールが出した **ZIP** をドラッグ&ドロップ。
   商品マスタ・出荷・入荷・レイアウトなど、入っている部分だけ反映されます。
   壊れたファイルや JSON でないものは**やさしくスキップ**され、止まりません。
3. **設計する（任意）**：「設計」タブで以下を編集。すべて即座に検証に反映されます。
   - **レイアウト**：ゾーンをドラッグで移動/リサイズ。棚は「通路×行間隔」で自動生成。
   - **設備**：AGV・コンベア・自動倉庫・梱包台をクリックで配置。
   - **フロー**：入荷→格納→ピッキング→梱包→出荷の各工程の方式（人手/AGV/コンベア/自動倉庫）を変更。
   - **躯体/CAD**：外壁やドック扉を作図、または DXF 図面を取り込み（mm/m 自動判定）。
4. **実行する**：「実行」で **2Dアニメーション**（作業員が動く）と **3Dビュー**（three.js）、
   KPI、提案 PNG が出ます。
5. **分析する**：処理能力（件/時）、ボトルネック工程、稼働率、サイクルタイム、
   そして **コスト**（1件あたり ¥・月間コスト・必要人員・投資回収月数）を確認。
6. **提案書を作る**：**PPTX**（PowerPoint で編集可）または **PDF** を書き出し。
   KPI 表＋レイアウト図＋前提（人件費率・AGV投資額・償却）が日本語で入ります。

---

## 5. シナリオ比較（役員に効く一枚）

「比較」タブで **現行 / 繁忙期（ピーク日）/ AGV導入** を並べ、差分を色分け表示します。

- **繁忙期**は需要を `peak_factor` 倍にしてセール期を再現。
- **AGV導入**は AGV を実際に動かし、少人数でもスループットを保てるか（省人化）を検証。
- 各案の **¥/件・必要人員・投資回収（月数）** まで見えるので、判断材料がそろいます。

---

## 6. コスト設定

「設定」で日本市場の標準値が最初から入っています（必要なら変更）。

- 人件費単価（¥/人時）
- 1日の稼働時間・月間稼働日数
- AGV の月額コスト、設備の capex/opex、償却月数

これらが KPI のコスト計算に直結します。提案 PNG にも前提として明記されます。

---

## 7. よくあるつまずき

- **何も入れていないのに動く？** → 仕様です。テンプレが仮値で全項目を埋めています。
- **ZIP を入れたら一部しか変わらない** → 正常。入っていたデータの部分だけ上書きします。
  どこが「あなたのデータ」かは出力フッターの「N% your data」で分かります。
- **日本語が文字化け（PNG/PPTX）** → Windows の Meiryo / 游ゴシック / MS ゴシックを自動使用します。
- **AGV を置いたのに動かない** → フローの「ピッキング」工程の方式を **AGV** に変えてください。

---

## 8. CLI（おまけ：手元で素早く回したいとき）

```bash
whsim templates                              # テンプレ一覧
whsim new acme -t ecommerce_small            # 作成（この時点で動く）
whsim estimate acme                          # 即時の概算（待ち行列式）
whsim run acme                               # シミュレーション実行
whsim render acme                            # 提案 PNG
whsim animate acme                           # 動く2D GIF（ブラウザ不要）
whsim simulate acme                          # run + render を一括
```

詳しくはトップの `README.md` を参照してください。
